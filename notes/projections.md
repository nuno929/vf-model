# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、既存理論の概念を主に以下へ射影する。

- K：各アクターがアクセス・利用可能な実質側の資源・資本・自由度
- P：各アクターが観測・参照可能で、意思決定に作用しうる名目・期待 stock
- A：各アクターの行動・意思決定
- ΔK：実現した実質変化
- ΔP：実現した名目・期待 stock の変化
- E[ΔK]：特定区間について形成される期待 flow

K / P / A は単一量を前提としない。個人でも K / P は多次元であり、A は観測区間内に複数存在しうる。マクロではさらに複数アクター分の K / P / A が同時に存在する。

```text
K_t = {K_i,t}
P_t = {P_i,t}
A_t = {A_i,t}
```

ここで集合は確率分布を意味しない。分布・平均・比率等は必要に応じて後段で作る分析上の射影である。

同じ環境でも、各アクターがアクセスできる資源・権限等が異なれば `K_i` は異なり、観測している情報、契約、信用、評価、制度との接続等が異なれば `P_i` は異なる。

したがって、主体間関係を別の普遍的な関係変数として置くことを前提としない。関係性は、各アクターから見た K へのアクセス可能性と P の観測・参照可能性へ反映される。

価値場の引力は別の変数として置かず、各アクターから見た多主体・多次元の K / P の関係から各 `A_i` が生じる構造として扱う。

E[ΔK] を独立して記述するのは、P が期待 stock、E[ΔK] が期待 flow だからである。E[ΔK] を A 生成の必須中間変数とはしない。

## 2. 経済学への射影候補

### 名目／実質・期待／実現

```text
P_i,t      : アクター i が観測・参照可能な名目・期待 stock
K_i,t      : アクター i がアクセス・利用可能な実質 stock
A_i,t      : アクターごとの行動・意思決定
ΔP         : 名目・期待 stock の実現変化
ΔK         : 実質 stock の実現変化
E_i,t[ΔK]  : 特定区間について形成される期待 flow
```

価値場は、各アクターから見た多主体・多次元の K / P の配置が、各 A にどの方向性を与えるかとして読む。

P は履歴依存の stock として扱い、現在の P に外生的に見える変化も、原則として観測窓以前の A や実現 ΔK の履歴が織り込まれた状態として読む。

具体的な名目／実質変換関係や期待形成式は、対象とする経済理論が持つ関係式を用いる。

### ミクロ均衡への射影

ミクロ経済学への射影では、各主体が将来の実質変化について持つ `E_i,t[ΔK]` と、それに基づく A の相互作用を均衡過程として読む。

```text
{E_i,t[ΔK]}
      ↓
   {A_i,t}
      ↓
既存ミクロ経済学の均衡過程
```

ここで均衡対象として強調するのは、実現済みの ΔK そのものではなく、**各主体が見込む期待 ΔK と、それに基づく行動の相互調整**である。

価格・取引条件・数量等の具体的な調整機構は、対象とするミクロ経済理論へ委ねる。価値場理論側で独自の均衡式は置かない。

### マクロ均衡への射影

マクロ側では、ミクロと時間構造が異なる。

前区間に実現した `ΔK_{t-1}` は当期の K、すなわち実質経済の状態・制約へ反映される。一方、当期の `ΔP_t` は名目・期待側の変化として P に作用し、当期以降の A と次の実質変化 `ΔK_t` を変える。

```text
ΔK_{t-1}
   ↓
  K_t  ←→  P_t
            ↑
           ΔP_t
             ↓
           {A_i,t}
             ↓
           ΔK_t
```

この意味で、ケインズ的なマクロ経済の調整過程は、**前区間までに実現した実質側の変化と、当期の名目・期待側の変化が相互作用する均衡過程**として K / P 上へ射影できる。

国家スケールでは、金利や通貨供給量の操作は ΔP 側への代表的な介入として扱える。これらが消費・投資・雇用等の A を通じて次の ΔK に作用する具体的な関係は、既存マクロ経済学のモデルへ委ねる。

この構造は国家固有ではない。P は A によって変化させられるため、**ΔP への介入は個人・組織・市場・国家等の各観測スケールで成立しうる**。価格提示、契約条件、評価、信用条件、制度変更等は、そのスケールに応じた P 側への介入候補である。

### 選好

既存経済学の選好概念を独立したコア変数には対応させない。

同一対象・同一実質条件に対する主体間の選択差は、P の構造差・量的差と、それによって形成される期待 ΔK の差として記述する。

### 消費 / 供給

消費と供給を別の存在論として置かず、各アクターの A を異なる主体・方向・会計視点から見たラベルとして扱う。

### 効用

効用は独立した普遍的原始量とはせず、特定の理論・目的において、期待 ΔK や K / P の関係をスカラーへ射影した表現として扱う候補とする。

### 資本

現在利用可能な設備・金融資源・知識等は K の構成要素として扱う。必要に応じて各アクター・各成分へ分解する。

> 注記：減価償却・自然損耗等、A を介さない K の変化を扱う場合は、既存理論の定義・計測方法へ射影する。

### 外部性

```text
A_i -> ΔK_j   (i != j)
A_i -> ΔP_j   (i != j)
```

観測範囲外のアクターによる A は、観測上は外部に見えても非主体的変化とは区別する。

## 3. 市場・ネットワークへの射影候補

市場では、複数アクター間でアクセス可能な K と観測・参照可能な P が異なり、その差を含む配置から各 A が生じ、その結果が資本・流動性・取引・人材等の変化として現れる。

- ノード：個人、企業、組織、制度単位など
- K：各ノードからアクセス可能な多次元状態
- P：各ノードから観測・参照可能な多次元期待状態
- A：各アクターの取引、投資、移動、契約等
- 集約 proxy：ΔP / ΔK
- エッジ：資源アクセス、情報伝播、契約、信用関係等を説明する応用上の表現

A を一つの「市場行動」へ自動的に集約しない。

---

## 4. 通貨・信用への射影候補

### 通貨

通貨を、価値判断を同期し、流動を可能にするプロトコルとして機能的に捉える案。

国家スケールでは、通貨供給量の変更は P 側への介入を表す代表的なマクロ経済学上の射影候補となる。

### 金利

金利を P そのものと同一視はしないが、貨幣需要・信用条件・投資判断等を通じて P 側を動かす代表的な調整・介入変数として射影できる。

### 信用

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える期待・評価・返済見込み：P

### 信用崩壊

P 上で成立していた期待が実現 ΔK によって十分に裏づけられず、その後の P の維持・形成が変化する現象として記述する案。

---

## 5. 国家・政治・組織への射影候補

国家や組織を単一主体として前提化せず、内部の複数アクターと、そのアクターごとに異なる K / P / A を必要な解像度で扱う。

- 公約・宣言：A を通じた P への作用
- 支持率・評価等の変化：ΔP の proxy
- 政策担当者・有権者・組織等の意思決定：各 A_i
- 実質結果：ΔK の proxy
- 国家の金融政策：金利・通貨供給量等を通じた ΔP 側への介入

単一主体へ還元する場合は集約規則を明示する。

## 6. 既存経済学との対応表候補

| 既存概念 | 主な射影候補 |
| --- | --- |
| 資源・予算制約 | K の各成分とアクセス可能性 |
| 選好 | P の構造差・量的差 / 期待 ΔK |
| 行動・取引 | 各 A_i |
| 名目側の実現変化 | ΔP |
| 実質側の実現変化 | ΔK |
| 名目・期待・信用 | P |
| 期待 flow | E[ΔK] |
| 実質・資本状態 | K |
| 効用 | 期待 ΔK または K / P のスカラー射影 |
| 外部性 | `A_i -> ΔK_j / ΔP_j` |
| ミクロ均衡 | 各主体の期待 ΔK と、それに基づく A の相互調整 |
| マクロ均衡 | 前区間 ΔK が形成する実質側と、当期 ΔP による名目・期待側の相互調整 |
| 金利・通貨供給量 | 国家スケールにおける ΔP 側への代表的介入 |
| 市場 | アクターごとに異なる K / P / A の接続系 |

---

## 7. 射影時に明示するもの

1. 対象アクター集合
2. 観測スケール
3. 時間幅
4. 各アクターの K へのアクセス範囲
5. 各アクターの P の観測・参照範囲
6. K / P の対象成分
7. A の観測単位
8. E[ΔK] の時間窓
9. ΔP / ΔK をどの proxy として使うか
10. ΔP への介入を扱う場合は、その作用主体と具体的手段
11. ミクロ／マクロ均衡へ射影する場合は、対象理論の具体的な均衡・調整機構
12. 集約規則
13. 分布化・平均化等を行う場合の情報損失
