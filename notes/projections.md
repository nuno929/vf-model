# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、既存理論の概念を主に以下へ射影する。

- K：資源・自由度
- ΔK：実現した資源変化
- P：将来の行動・結果に対して形成される多次元の期待構造
- A：行為

**価値場は K と P の配置・関係として扱い、独立した価値場変数は置かない。**

選好・好き嫌い・合理性の差は独立した選好変数には置かず、主体ごとの P の構造差・量的差と、そこから形成される期待 ΔK の差として扱う。

射影時には、観測主体・観測スケール・時間幅・対象資源・集約規則を明示する。

経済学へ射影する場合、P は名目・期待側、K / ΔK は実質・実現側として対応させる。ただし、両者の具体的な動学関係は価値場理論側で普遍式を定義せず、対象とする経済学理論が持つ名目／実質・期待／実現の関係式を参照する。

## 2. 経済学への射影候補

### 名目／実質・期待／実現

```text
P_t                    : 名目・期待側の stock
K_t / ΔK_t             : 実質・実現側
E_t[ΔK_t] = f(P_t, ΔK_{t-1}) : 期待 flow
```

P は `E[ΔK]` そのものではなく、契約・信用・制度・金融・宣言等によって実体変化と独立に形成・介入されうる期待構造である。

具体的な変換関係は、名目金利／実質金利、名目賃金／実質賃金、名目GDP／実質GDP、期待収益／実現収益など、各経済理論・分析対象がすでに持つ関係式を用いる。

### 選好

既存経済学の選好概念を独立したコア変数には対応させない。

同一対象・同一実体条件に対する主体間の選択差は、P の構造差・量的差と、それによって異なる期待 ΔK が形成されることとして記述する。

### 消費 / 供給

消費と供給を別の存在論として置かず、同じ資源変換 A を異なる主体・方向・会計視点から見たラベルとして扱う。

```text
A : K_t -> K_{t+1}
```

### 効用

効用は独立した普遍的原始量とはせず、特定の理論・目的において、期待 ΔK や K / P の関係をスカラーへ射影した表現として扱う候補とする。

### 資本

現在利用可能な設備・金融資源・知識等は K の構成要素として扱う。過去の A / ΔK によって形成された再利用可能な構造を別途分析する場合は、履歴依存構造として射影する。

### 外部性

```text
A_i -> ΔK_j   (i != j)
```

### 均衡

静的均衡をコア前提にはせず、一定観測窓で更新速度が小さい局所安定配置として射影する候補。

```text
E[ΔK] ≈ 0
E[ΔP] ≈ 0
```

## 3. 市場・ネットワークへの射影候補

価値場を市場として記述する場合、複数ノード間の K / P の配置と、A / ΔK の接続を見る。

- ノード：個人、企業、組織、制度単位など
- エッジ：資源変換、情報伝播、契約、信用関係
- 減衰：摩擦、遅延、不確実性、制度、情報損失等

```text
ΔK_j = R_{ij}(P, C) · A_i + ε
```

---

## 4. 通貨・信用への射影候補

### 通貨

通貨を、価値判断を同期するためのプロトコルとして機能的に捉える案。

### 信用

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える期待・評価・返済見込み：P

### 信用崩壊

P 上で成立していた期待が実現局面で K / ΔK を要求し、資源制約との両立不能が露呈する現象として記述する案。

---

## 5. 国家への射影候補

国家を価値場理論の原始主体とはせず、通貨・制度・信用・資源配分を通じて形成される大域的ネットワークとして射影する案。

### 通貨圏

同一通貨・決済・債務体系に実効的に接続する主体群を価値同期圏として扱う。

- 税・規制：K / P の配置への介入
- 福祉・移転：K の再配分・下支え
- 金融政策：P と資源アクセス条件の調整
- 国境・法：接続条件の設定

---

## 6. 政治への射影候補

- 公約・宣言：将来 ΔK に関する P の形成
- 実現：観測された ΔK
- 支持率・評価：P の変化を観測する候補

---

## 7. 組織・階層への射影候補

個人・企業・制度などを固定階層として定義するのではなく、分析対象ごとに有効力学系を切る。

組織では、個人行動の調整、資源再配分、契約、評価、権限などを内生化する。社会では、その組織・個人の分布や制度をさらに内生化する。

---

## 8. 倫理・大義・功利主義への時間軸射影候補

規範そのものをコア変数にはしないが、異なる時間軸の期待 ΔK として射影する余地がある。

- 倫理：過去・現在の被害や摩擦を抑える短期裁定
- 大義：未来の可能性・探索・未完成を正当化する長期配向
- 功利主義：基盤の効率・摩擦最小化を行う現在〜中期最適化

---

## 9. 既存経済学との対応表候補

| 既存概念 | 主な射影候補 |
| --- | --- |
| 資源・予算制約 | K / C |
| 選好 | P の構造差・量的差 / 期待 ΔK |
| 行動・取引 | A |
| 実現成果 | ΔK |
| 名目・期待・信用 | P |
| 実質・実現 | K / ΔK |
| 効用 | 期待 ΔK または K / P のスカラー射影 |
| 外部性 | `A_i -> ΔK_j` |
| 均衡 | 局所安定配置 |
| 資本 | K または A/ΔK の履歴構造 |
| 市場 | 多主体の K / P / A / ΔK 接続系 |

## 10. VVRC との関係

VVRC を外部の別理論として接続するのではなく、価値場理論の低次元・時間平均・マクロ寄りの射影として扱う案。
