# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、既存理論の概念をそのまま原始変数として採用せず、主に以下へ射影する。

- K：資源
- ΔK：実現した資源変化
- P：期待・信念・信用・制度的背景等の場
- X：選好方向
- A：行為
- V：方向・圧力・勾配の派生表現

射影時には、観測主体・観測スケール・時間幅・対象資源・集約規則を明示する。

---

## 2. 経済学への射影候補

### 消費 / 供給

消費と供給を別の存在論として置かず、同じ資源変換 A を異なる主体・方向・会計視点から見たラベルとして扱う。

```text
A : K_t -> K_{t+1}
```

### 効用

X または V の多元構造を、特定目的のためにスカラーへ射影したものとして扱う候補。

```text
U = u(X, V | context)
```

### 資本

「資本」は用法が複数あるため、コア変数にはしない。

1. 現在利用可能な設備・金融資源・知識等を指す場合：K の一部
2. 過去の A / ΔK によって形成された再利用可能な構造を指す場合：履歴依存構造

```text
Capital_t = H(A_{<t}, ΔK_{<t})
```

### 外部性

ある主体 i の行為が別主体 j の資源変化を生む構造として扱う。

```text
A_i -> ΔK_j   (i != j)
```

### 均衡

静的均衡をコア前提にはせず、一定観測窓で更新速度が小さい局所安定配置として射影する候補。

```text
E[ΔK] ≈ 0
E[ΔP] ≈ 0
```

## 3. 市場・ネットワークへの射影候補

価値場を市場として記述する場合、複数ノード間の相互期待・反応・減衰を扱う。

- ノード：個人、企業、組織、制度単位など
- エッジ：価値変換、情報伝播、契約、信用関係
- 反応係数：ノード固有ではなく接続側に置くこともできる
- 減衰：摩擦、遅延、不確実性、制度、情報損失等

```text
ΔK_j = R_{ij}(P, C) · A_i + ε
```

サプライチェーン、バリューチェーン、信用ネットワーク等を同じ関係系へ射影する余地がある。

---

## 4. 通貨・信用への射影候補

### 通貨

通貨を、価値判断を同期するためのプロトコルとして機能的に捉える案。

- 比較可能性
- 時間を越えた保存
- 他者との交換・同期

### 信用

信用は K と P の双方にまたがる。

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える期待・評価・返済見込み：P

### 信用崩壊

応用モデルとして、P 上で同時成立可能に見えた期待が実現局面で同時に K / ΔK を要求し、基底資源制約との両立不能が露呈する現象として記述する案。

---

## 5. 国家への射影候補

国家を価値場理論の原始主体とはせず、通貨・制度・信用・資源配分を通じて形成される大域的ネットワークとして射影する案。

### 通貨圏

同一通貨・決済・債務体系に実効的に接続する主体群を価値同期圏として扱う。

- 税・規制：可到達性・勾配の調整
- 福祉・移転：K の再配分・下支え
- 金融政策：P と資源アクセス条件の調整
- 国境・法：接続条件 C の設定

「国家 = 通貨圏」はコア定義ではなく、国家論への射影仮説として保持する。

### 準分散ネットワーク

- 人口・企業：ノード
- 税・福祉・金融・法：プロトコル
- 移住・資本移動：ネットワーク間移動
- 信認崩壊：接続維持条件の崩壊

という対応も検討対象。

---

## 6. 政治への射影候補

- 公約・宣言：将来 ΔK に関する P の形成
- 実現：観測された ΔK
- 支持率・評価：実績観測後の ΔP を推定する観測候補

支持率や選挙結果を ΔP そのものと同一視せず、観測の一つとして扱う。

---

## 7. 組織・階層への射影候補

個人・企業・制度などを固定階層として定義するのではなく、分析対象ごとに有効力学系を切る。

組織では、個人行動の調整、資源再配分、契約、評価、権限などを内生化する。社会では、その組織・個人の分布や制度をさらに内生化する。

重要なのは上位主体を単一意思として実体化せず、集約規則を明示すること。

---

## 8. 倫理・大義・功利主義への時間軸射影候補

規範そのものをコア変数にはしないが、異なる時間軸の最適化原理として射影する案がある。

- 倫理：過去・現在の被害や摩擦を抑える短期裁定
- 大義：未来の可能性・探索・未完成を正当化する長期配向
- 功利主義：基盤の効率・摩擦最小化を行う現在〜中期最適化

異なる時間軸の最適化を同一レイヤーで最大化しようとするとトレードオフが生じる、という動学仮説として扱う。

## 9. 既存経済学との対応表候補

| 既存概念 | 主な射影候補 |
| --- | --- |
| 資源・予算制約 | K / C |
| 選好 | X |
| 行動・取引 | A |
| 実現成果 | ΔK |
| 期待・信用 | P |
| 効用 | X / V のスカラー射影 |
| 外部性 | `A_i -> ΔK_j` |
| 均衡 | 局所安定配置 |
| 資本 | K または A/ΔK の履歴構造 |
| 市場 | 多主体の A / P / ΔK 接続系 |

## 10. VVRC との関係

VVRC を外部の別理論として接続するのではなく、価値場理論の低次元・時間平均・マクロ寄りの射影として扱う案。

これはコア定義ではなく、既存成果との対応付けとして保持する。
