# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、既存理論の概念を主に以下へ射影する。

- K：各アクターの実質側の資源・資本・自由度
- P：各アクターまたは共有レイヤーの名目・期待 stock
- A：各アクターの行動・意思決定
- ΔK：実現した実質変化
- ΔP：実現した名目・期待 stock の変化

K / P / A は単一量を前提としない。個人でも K / P は多次元であり、A は観測区間内に複数存在しうる。マクロではさらに複数アクター分の K / P / A が同時に存在する。

```text
K_t = {K_i,t}
P_t = {P_i,t}
A_t = {A_i,t}
```

ここで集合は確率分布を意味しない。分布・平均・比率等は必要に応じて後段で作る分析上の射影である。

価値場の引力は別の変数として置かず、多主体・多次元の K / P の関係から各 `A_i` が生じる構造として扱う。

個人単位では A を比較的直接観測できるが、集約レベルでは観測コストが高くなる。そのため、名目側の ΔP と実質側の ΔK を、A の集積・流動を捉える主要 proxy として用いる。

## 2. 経済学への射影候補

### 名目／実質・期待／実現

```text
P_i,t                  : アクターごとの名目・期待 stock
K_i,t                  : アクターごとの実質 stock
A_i,t                  : アクターごとの行動・意思決定
ΔP                     : 名目・期待 stock の実現変化
ΔK                     : 実質 stock の実現変化
E_i,t[ΔK]              : 主体・対象・時間軸ごとの期待 flow
```

価値場は、多主体・多次元の K / P の配置が、各アクターの A にどの方向性を与えるかとして読む。

具体的な名目／実質変換関係は、対象とする経済理論が持つ関係式を用いる。

### 選好

既存経済学の選好概念を独立したコア変数には対応させない。

同一対象・同一実質条件に対する主体間の選択差は、P の構造差・量的差と、それによって形成される期待 ΔK の差として記述する。

### 消費 / 供給

消費と供給を別の存在論として置かず、各アクターの A を異なる主体・方向・会計視点から見たラベルとして扱う。

### 効用

効用は独立した普遍的原始量とはせず、特定の理論・目的において、期待 ΔK や K / P の関係をスカラーへ射影した表現として扱う候補とする。

### 資本

現在利用可能な設備・金融資源・知識等は K の構成要素として扱う。必要に応じて各アクター・各成分へ分解する。

### 外部性

```text
A_i -> ΔK_j   (i != j)
```

### 均衡

静的均衡をコア前提にはせず、一定観測窓で ΔP / ΔK の変化が小さい局所安定配置として射影する候補。

## 3. 市場・ネットワークへの射影候補

市場では、複数アクター間の K / P の配置が各 A を生み、その結果が資本・流動性・取引・人材等の変化として現れる。

- ノード：個人、企業、組織、制度単位など
- K / P：各ノードの多次元状態
- A：各アクターの取引、投資、移動、契約等
- 集約 proxy：ΔP / ΔK
- エッジ：資源変換、情報伝播、契約、信用関係

A を一つの「市場行動」へ自動的に集約しない。

---

## 4. 通貨・信用への射影候補

### 通貨

通貨を、価値判断を同期し、流動を可能にするプロトコルとして機能的に捉える案。

### 信用

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える期待・評価・返済見込み：P

### 信用崩壊

P 上で成立していた期待が実現局面で K / ΔK を要求し、資源制約との両立不能が露呈する現象として記述する案。

---

## 5. 国家への射影候補

国家を価値場理論の原始主体とはせず、複数アクター・制度・通貨・信用・資源配分の接続系として扱う。

国家全体を単一の K / P / A へ還元する場合は、その集約規則を明示する。

---

## 6. 政治への射影候補

- 公約・宣言：P の形成
- 支持率・評価等の変化：ΔP の proxy
- 政策担当者・有権者・組織等の意思決定：各 A_i
- 実質結果：ΔK の proxy

---

## 7. 組織・階層への射影候補

組織を単一主体として前提化せず、内部の複数アクターとその K / P / A を必要な解像度で扱う。

組織レベルの指標を使う場合は、それがどの個人・部門・資源・期待をどの規則で集約したものかを明示する。

---

## 8. 既存経済学との対応表候補

| 既存概念 | 主な射影候補 |
| --- | --- |
| 資源・予算制約 | K の各成分 |
| 選好 | P の構造差・量的差 / 期待 ΔK |
| 行動・取引 | 各 A_i |
| 名目側の実現変化 | ΔP |
| 実質側の実現変化 | ΔK |
| 名目・期待・信用 | P |
| 実質・資本状態 | K |
| 効用 | 期待 ΔK または K / P のスカラー射影 |
| 外部性 | `A_i -> ΔK_j` |
| 均衡 | ΔP / ΔK が小さい局所安定配置 |
| 市場 | 多主体・多次元の K / P / A 接続系 |

---

## 9. 射影時に明示するもの

1. 対象アクター集合
2. 観測スケール
3. 時間幅
4. K の対象成分
5. P の対象成分
6. A の観測単位
7. ΔP / ΔK をどの proxy として使うか
8. 集約規則
9. 分布化・平均化等を行う場合の情報損失
10. 規範評価を含むか否か
