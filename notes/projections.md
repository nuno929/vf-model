# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、既存理論の概念を主に以下へ射影する。

- K：各アクターがアクセス・利用可能な実質側の資源・資本・自由度
- P：各アクターの将来の見通し・評価・選好・信用・信念等を保持する期待形成側の stock
- A：各アクターの行動・意思決定
- ΔK_i：各アクターに実現した実質変化
- ΔP_i：各アクターに実現した P stock の変化
- E_i[ΔK]：特定対象・区間について形成される期待値 flow

K / P / A は単一量を前提としない。個人でも K / P は多次元であり、A は観測区間内に一つ以上存在しうる。マクロではさらに複数アクター分の K / P / A が同時に存在する。

```text
K_t = {K_i,t}
P_t = {P_i,t}
A_t = {A_i,t}
ΔK_t = {ΔK_i,t}
ΔP_t = {ΔP_i,t}
```

ここで集合は確率分布や集約スカラーを意味しない。分布・平均・比率・合計等は必要に応じて後段で作る分析上の射影である。

K / P の境界は、主体が実際に利用・行使・参照可能な資源・能力・権利・情報等を K、それらを含む環境について主体が保持する見通し・評価・信用・信念等を P とする。

価値場の引力は別の変数として置かず、各アクターから見た多主体・多次元の K / P の関係から各 `A_i` が生じる構造として扱う。

P を「期待 stock」と呼ぶのは、P 自体を時点的な期待値とみなすためではなく、将来価値への期待や行動を生成する側の蓄積構造であることに着目した呼称である。`E[ΔK]` は現在の K / P から特定対象・区間について形成される期待値 flow として区別する。

## 2. 経済学への射影候補

### 名目／実質・期待／実現

```text
P_i,t       : アクター i の期待形成側 stock
K_i,t       : アクター i がアクセス・利用可能な実質 stock
A_i,t       : アクターごとの行動・意思決定
ΔP_i,t      : アクター i の P stock の実現変化
ΔK_i,t      : アクター i の実質 stock の実現変化
E_i,t[ΔK]   : 特定対象・区間について形成される期待値 flow
```

価値場は、各アクターから見た多主体・多次元の K / P の配置が、各 A にどの方向性を与えるかとして読む。

P は履歴依存の stock として扱い、現在の P に外生的に見える変化も、初期状態を除けば原則として観測窓以前の A や実現 ΔK の履歴が織り込まれた状態として読む。

具体的な名目／実質変換関係や期待形成式は、対象とする経済理論が持つ関係式を用いる。

### ミクロ均衡への射影

ミクロ経済学への射影では、各主体が将来の実質変化について持つ `E_i,t[ΔK]` と、それに基づく A の相互作用を均衡過程として読む。

```text
{E_i,t[ΔK]}
      ↓
   {A_i,t}
      ↓
既存ミクロ経済学の均衡過程
```

ここで均衡対象として強調するのは、実現済みの ΔK そのものではなく、**各主体が見込む期待 ΔK と、それに基づく行動の相互調整**である。

#### 期待総余剰

VFTでは消費側と供給側を別の存在論へ分離しない。交換取引を一定の観測範囲で集約する場合、主体間の単なる K の移転分は相殺され、その範囲に残る期待実質変化を

```text
Σ_i E_i,t[ΔK]
```

として読むことができる。これを **期待総余剰（expected total surplus）** への射影とする。

ここでいう期待総余剰は、consumer surplus / producer surplus を独立に定義して加算する意味ではなく、**VFTの多次元 K 上で、主体間移転を相殺した後に残る期待実質変化**を指す。K が多次元なら、この総余剰も多次元のままでよく、単一スカラーへの換算を前提としない。

したがって、これは VFT の新たな Core 変数でも、独立した効用尺度でもない。射影先で特定の価値尺度へスカラー化する場合は、その評価写像を別途明示する。

価格・取引条件・数量等の具体的な調整機構は、対象とするミクロ経済理論へ委ねる。価値場理論側で独自の均衡式は置かない。

### 金融市場への射影

金融市場は、期待総余剰に関する期待と、名目側の実現変化 `ΔP` が、価格・金利・利回り・信用条件等に比較的明瞭に表出する観測領域として扱う。

ここで金融市場を、期待 ΔK を別の変数へ変換する装置として定義するわけではない。交換から生じる期待総余剰と、P stock の変化 `ΔP` が観測しやすく現れる領域として位置づける。

また、十分な量の実取引で単価が変化すれば、それに対する主体の見通し・評価・信用等が変わり、結果として P 側の変化へ波及しうる。具体的な波及関係は対象とする既存経済理論へ委ねる。

### マクロ均衡への射影

マクロ側では、ミクロと時間構造が異なる。

前区間に実現した `{ΔK_i,t-1}` は当期の実質側の状態・制約へ反映される。一方、当期に生じる `{ΔP_i,t}` は各主体の期待形成側 stock の変化であり、当期以降の A と次の実質変化へ作用する。

ただし、`ΔP` 自体を外部から直接投入する介入変数とはしない。政策・価格提示・契約条件変更・制度変更等は、まず介入主体の A として記述する。

```text
A_policy,t
    ↓
{ΔP_i,t}
    ↓
{P_i,t+1}
    ↓
{A_i,t+1}
    ↓
{ΔK_i,t+1}
```

この因果経路を含め、前区間までに実現した実質側の変化と、当期の A によって誘発される名目・期待形成側の変化が相互作用する過程を、既存マクロ経済学の調整過程へ射影する。

国家スケールでは、政策金利の変更や通貨供給量の操作は政策主体の代表的な A であり、それらが各主体の見通し・信用条件等を変え、`ΔP_i` を誘発するものとして扱う。

この構造は国家固有ではない。個人・組織・市場・国家等の各観測スケールで、P の変化を誘発する介入 A を扱うことができる。

### 選好

既存経済学の選好概念を独立したコア変数には対応させない。

同一対象・同一実質条件に対する主体間の選択差は、P の構造差・量的差と、それによって形成される期待 ΔK の差として記述する。

### 消費 / 供給

消費と供給を別の存在論として置かず、各アクターの A を異なる主体・方向・会計視点から見たラベルとして扱う。

### 効用

効用は独立した普遍的原始量とはせず、特定の理論・目的において、期待 ΔK や K / P の関係をスカラーへ射影した表現として扱う候補とする。

### 資本

現在利用可能な設備・金融資源・知識等は K の構成要素として扱う。必要に応じて各アクター・各成分へ分解する。

> 注記：減価償却・自然損耗等、A を介さない K の変化を扱う場合は、既存理論の定義・計測方法へ射影する。

### 外部性

```text
A_i -> ΔK_j   (i != j)
A_i -> ΔP_j   (i != j)
```

観測範囲外のアクターによる A は、観測上は外部に見えても非主体的変化とは区別する。

## 3. 市場・ネットワークへの射影候補

市場では、複数アクター間でアクセス可能な K と期待形成側の P が異なり、その差を含む配置から各 A が生じ、その結果が資本・流動性・取引・人材等の変化として現れる。

- ノード：個人、企業、組織、制度単位など
- K：各ノードからアクセス可能な多次元状態
- P：各ノードが保持する多次元の期待形成側状態
- A：各アクターの取引、投資、移動、契約等
- 集約 proxy：ΔP / ΔK
- エッジ：資源アクセス、情報伝播、契約、信用関係等を説明する応用上の表現

A を一つの「市場行動」へ自動的に集約しない。

---

## 4. 通貨・信用への射影候補

### 通貨

通貨を、価値判断を同期し、流動を可能にするプロトコルとして機能的に捉える案。

国家スケールでは、通貨供給量の変更は政策主体の A として扱い、その結果として各主体の P 側に変化を誘発する代表的なマクロ経済学上の射影候補となる。

### 金利

金利を P そのものと同一視はしない。政策金利の変更や金利条件の提示は A として扱い、貨幣需要・信用条件・投資判断等を通じて各主体の P を変化させる調整経路として射影する。

### 信用

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える評価・返済見込み・将来見通し：P

### 信用崩壊

P 上で成立していた見通しが実現 ΔK によって十分に裏づけられず、その後の P の維持・形成が変化する現象として記述する案。

---

## 5. 国家・政治・組織への射影候補

国家や組織を単一主体として前提化せず、内部の複数アクターと、そのアクターごとに異なる K / P / A を必要な解像度で扱う。

- 公約・宣言：介入主体の A
- 支持率・評価等の変化：ΔP の proxy
- 政策担当者・有権者・組織等の意思決定：各 A_i
- 実質結果：ΔK の proxy
- 国家の金融政策：政策主体の A を通じて各主体の ΔP を誘発する経路

単一主体へ還元する場合は集約規則を明示する。

## 6. 既存経済学との対応表候補

| 既存概念 | 主な射影候補 |
| --- | --- |
| 資源・予算制約 | K の各成分とアクセス可能性 |
| 選好 | P の構造差・量的差 / 期待 ΔK |
| 行動・取引 | 各 A_i |
| 名目側の実現変化 | 各 ΔP_i とその集約 proxy |
| 実質側の実現変化 | 各 ΔK_i とその集約 proxy |
| 名目・期待・信用 | P |
| 期待値 flow | E[ΔK] |
| 期待総余剰 | 交換範囲内で主体間移転を相殺した `Σ_i E_i[ΔK]`。多次元 K なら多次元のまま扱う |
| 実質・資本状態 | K |
| 効用 | 期待 ΔK または K / P のスカラー射影 |
| 外部性 | `A_i -> ΔK_j / ΔP_j` |
| ミクロ均衡 | 各主体の期待 ΔK と、それに基づく A の相互調整 |
| マクロ均衡 | 前区間の実質変化と、当期の A が誘発する名目・期待形成側変化の相互調整 |
| 金融市場 | 期待総余剰に関する期待と ΔP が価格・金利・利回り・信用条件等へ表出しやすい観測領域 |
| 金利・通貨供給量 | P の変化を誘発する政策主体の代表的 A |
| 市場 | アクターごとに異なる K / P / A の接続系 |

## 7. 射影時に明示するもの

1. 対象アクター集合
2. 観測スケール
3. 時間幅
4. 各アクターの K へのアクセス範囲
5. 各アクターの P の対象範囲
6. K / P の対象成分と境界原則
7. A の観測単位と、必要に応じたイベント順序
8. E[ΔK] の時間窓
9. 期待総余剰として集約する場合は、対象とする交換範囲・K次元・相殺する移転の境界
10. ΔP / ΔK をどの proxy として使うか
11. P 側への介入を扱う場合は、その作用主体の A と、どの ΔP_i を誘発するとみなすか
12. ミクロ／マクロ均衡へ射影する場合は、対象理論の具体的な均衡・調整機構
13. 集約規則
14. 分布化・平均化等を行う場合の情報損失
