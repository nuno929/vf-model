# 価値場理論 — 既存概念・応用への射影ノート

> この文書は価値場理論のコア定義ではなく、既存概念・応用領域への射影候補を保存するためのノートである。

## 1. 射影の基本方針

価値場理論では、

- `K`：共通の実資源世界
- `K_i`：K のうち主体 `i` がアクセス・利用可能な範囲
- `P_i`：主体 `i` の期待形成側 stock
- `A_i`：主体 `i` の行動・意思決定
- `ΔK(S, τ)`：対象範囲 `S`・時間区間 `τ` に実現した実資源量の差分（総量変化）
- `ΔP_i`：主体 `i` の P に実現した区間差分
- `E_i[ΔK(S, τ)]`：主体 `i` が対象範囲・区間について形成する期待実資源変化

を用いる。

K の資源世界そのものは主体ごとに別々に存在しない。actor-relative なのは、各主体が利用できる `K_i`、各主体の `P_i`、およびそこから形成される期待評価 `E_i[ΔK]` である。

`ΔK` は actor-relative な別資源世界を表さない。個人・市場・社会で変わるのは対象主体、時間区間、資源範囲、集約規則であり、実資源差分としての型は同じである。

## 2. 経済学への射影候補

### 資源・期待・実現

```text
K_t               : 共通の実資源状態
K_i,t             : 主体 i が利用可能な K の範囲
P_i,t             : 主体 i の期待形成状態
A_i,t             : 主体 i の行動・意思決定
ΔK(S, τ)          : 対象範囲・区間で実現した実資源差分
ΔP_i,t            : 主体 i に実現した期待形成状態の差分
E_i[ΔK(S, τ)]     : 主体 i が形成する期待実資源差分
```

Core の K / P を経済学上の real / nominal と同一視しない。K は resource / capability side、P は expectation / valuation side として置き、real / nominal の語は対象とする経済理論への具体的射影でのみ用いる。

### 主体別期待と意思決定

経済射影では、`K_i` を主体 `i` の予算・保有資源・供給能力等の制約側、`P_i` を価格、他主体の生産・消費、信用、将来条件等についての見通しを含む期待形成側として読める。

主体 `i` は、自らが利用可能な `K_i` と、他主体・価格・将来条件等について形成された `P_i` のもとで、自らが生産・消費すると見込む実資源差分 `E_i[ΔK(S, τ)]` を形成し、A を選択する。

```text
K_i                         P_i
予算・保有資源・             価格・他主体の行動・
供給能力等の制約             将来条件等への見通し
          \                 /
           \               /
            E_i[ΔK(S, τ)]
                    ↓
                   A_i
```

この意味で、主体の意思決定は自己完結的ではない。他主体の動きについての予測が `P_i` に入り、自身の資源制約 `K_i` と組み合わされて期待生産・期待消費を形成する。

### 期待側の均衡

同一の `S`・`τ`・会計規則のもとで、主体ごとの期待生産・期待消費が相互に整合する状態を、既存経済学上の均衡へ射影できる。

生産を正、消費を負とする符号規則を採り、在庫変化・輸出入・外生流入等の境界項がない閉じた scope では、概念的な期待均衡条件を

```text
Σ_i E_i[ΔK(S, τ)] ≈ 0
```

と表せる。

境界項がある場合は、在庫、輸出入、外生的な供給・消滅等を含む収支条件として扱う。したがって `Σ_i E_i[ΔK] ≈ 0` は VFT の普遍式ではなく、対象となる経済射影で scope・符号規則・境界条件を固定した場合の均衡表現である。

価格、取引、契約、在庫、信用条件等の observable が各主体の `P_i` を更新し、それに応じて `E_i[ΔK]` と A が修正されることで、期待の不整合が調整されうる。

```text
{K_i, P_i}
     ↓
{E_i[ΔK]}
     ↓
{A_i}
     ↓
price / trade / inventory / credit / observed ΔK
     ↓
{ΔP_i}
     ↓
{E_i[ΔK]} の再形成
```

### 「神の見えざる手」への射影

古典経済学における「神の見えざる手」は、VFT では、中央の主体が全体最適量を直接決定しなくても、各主体が `K_i` と `P_i` のもとで `E_i[ΔK]` を形成し、価格・取引・信用等を介して互いの期待を修正することで、期待生産・期待消費の不整合が分散的に調整される過程として射影できる。

この射影は、均衡が必ず社会的最適であることを意味しない。情報非対称、外部性、市場支配、信用制約、制度的不整合等によって、期待が整合しても望ましい配分になるとは限らない。

### ミクロ／マクロの接続

VFT ではミクロとマクロを別型の `ΔK` で分離しない。

主体ごとの `E_i[ΔK]` と A の相互作用、および実現した個別 `ΔK` をミクロな観測単位として扱う。同じ `ΔK` を主体集合・時間区間・資源範囲について集約することで、市場・産業・社会・マクロの観測単位へ接続する。

```text
{E_i[ΔK]} -> {A_i} -> {ΔK}
                         ↓ aggregate by actors / time / resource scope
                      aggregate ΔK
```

`aggregate ΔK` は別の Core 変数ではなく、同じ `ΔK` の集約表現である。

需要・供給はこの射影において、同一資源に対する主体別の符号付き期待変化を、生産側・消費側へ対応させる既存経済学上の表現として扱う。`E_i[ΔK]` 自体を desire や demand と Core 定義するわけではない。

### 期待変化の集約と余剰

比較可能な資源差分について単純和を採る場合、

```text
Σ_i E_i[ΔK]
```

はまず **aggregate expected resource change** として読む。

この `Σ` は、互いに無関係な actor-relative ベクトルを無条件に加算することを意味しない。少なくとも以下を射影先で明示する。

- 対象とする共通 K の範囲
- 対象主体集合
- 期待資源差分の比較可能性
- 集約に用いる会計・換算規則
- 共有資源・重複アクセスの扱い
- 時間区間

標準経済学上の consumer surplus / producer surplus / total surplus は、単なる資源量差分ではなく valuation、WTP / WTA、cost 等を含む概念である。したがって、`Σ_i E_i[ΔK]` をそのまま標準経済学上の expected total surplus と同一視しない。

VFT の期待変化を expected total surplus へ射影する場合は、対象理論側で utility / valuation / WTP / WTA / cost 等との mapping を追加的に明示する。この mapping が成立した場合にのみ、期待変化の集約を既存の surplus 概念へ接続する。

### 金融市場への射影候補

金融市場は、主体ごとの期待や評価が、価格・金利・利回り・信用条件等へ比較的明瞭に表出する観測領域として扱える。

価格・金利・信用条件は P そのものではない。K、A、制度、市場調整等の影響も受ける observable であり、P の集約的な現れを含む proxy 候補として扱う。

### マクロ政策への射影候補

政策金利の変更、通貨供給量の操作、制度変更等は、まず政策主体の A として記述する。

```text
A_policy,t
    ↓
{ΔP_i,t}
    ↓
{P_i,t+1}
    ↓
{E_i[ΔK], A_i}
    ↓
{ΔK_t+1}
    ↓ aggregate
macro-scale observation of ΔK
```

政策 A が各主体の見通し・信用条件等を変え、`ΔP_i` を誘発し、期待形成と行動を変えるという経路を対象とするマクロ経済モデルへ射影できる。

ここでも「マクロ固有の別種の ΔK」を導入するのではなく、個々に生じる同じ実資源差分 `ΔK` を対象スケールで集約する。

## 3. 選好・効用・消費・生産

### 選好

選好を独立した Core 変数には置かない。主体ごとの選好差は P の構造差として扱う。

### 消費 / 生産

消費と生産を別の存在論として置かず、各主体の A によって生じる実資源差分 `ΔK` の符号・資源種・会計視点として扱う。

主体ごとの `E_i[ΔK]` は、自らが消費・生産すると見込む資源差分を表しうる。経済射影では、同一 scope で符号付き期待差分を比較することで、需要・供給とその均衡へ接続する。

### 効用

効用は独立した普遍的原始量とはせず、特定理論・目的で K / P / `E[ΔK]` をスカラーへ射影する表現として扱う候補とする。

---

## 4. 資本・外部性・市場

### 資本

設備、知識、権利、現金、行使可能な金融請求権、利用可能な信用枠等、実際に利用可能で行動可能性を増やすものは K の構成要素として扱える。名目評価額そのものと K を同一視しない。

### 外部性

```text
A_i -> ΔK
A_i -> ΔP_j   (i != j)
```

主体 i の A が実資源差分 `ΔK` を生み、その結果として他主体の利用可能範囲 `K_j` や期待形成状態 `P_j` が変化する場合を外部性として記述できる。

### 市場・ネットワーク

市場では、共通 K に対する主体ごとのアクセス差 `K_i`、期待形成状態 `P_i`、期待差分 `E_i[ΔK]`、行動 `A_i`、実現差分 `ΔK` の相互作用を扱う。

ネットワークのノード・エッジは応用上の表現であり、Core の独立関係変数とはしない。

---

## 5. 通貨・金利・信用

### 通貨

通貨を価値判断・交換を同期するプロトコルとして機能的に読むことはできるが、Core 定義ではない。

### 金利

金利を P と同一視しない。政策金利の変更や金利条件の提示は A として扱い、その結果として主体の期待形成状態に変化を誘発する経路へ射影する。

### 信用

- 実際に利用可能な信用枠 → K / K_i
- 返済見込み・相手への信用・将来評価 → P_i

### 信用崩壊

P 上で成立していた見通しが実現 `ΔK` によって十分に裏づけられず、その後の P の形成・維持が変化する現象として記述できる。

---

## 6. 国家・政治・組織

国家や組織を自動的に単一主体として扱わない。

- 政策・公約・宣言：主体の A
- 支持率・評価等：P の proxy 候補
- 政策実施による資源差分：ΔK
- 政策等により誘発された期待変化：ΔP_i

単一主体へ還元する場合は近似条件と集約規則を明示する。

---

## 7. 射影時に明示するもの

1. 共通 K の対象範囲
2. 対象主体集合
3. 各主体の K へのアクセス範囲
4. P に用いる proxy
5. A の観測単位
6. 時間窓 `τ`
7. 資源 scope `S`
8. ΔK / ΔP の操作化
9. `E_i[ΔK]` の期待対象となる消費・生産等の範囲
10. 期待均衡を扱う場合の符号規則・境界項・会計規則
11. 共有資源・重複アクセスの扱い
12. surplus へ射影する場合の valuation / utility / WTP / WTA / cost mapping
13. 均衡・調整過程へ射影する対象理論
14. 情報損失
