# 価値場理論 — 既存理論との接続ノート

> この文書は Core 定義ではなく、VFT が既存理論のどの構造を参照・一般化・再配置するかを整理する。

VFT の目的は既存理論との同一性を主張することではない。

重要なのは、

> どの構造を保持し、どの固有仮定を外しているか

を明確にすることである。

---

## 1. Marxian categories

VFT が明示的に参照する主要な区別：

- use-value
- labor
- exchange-value
- surplus
- accumulation

VFT では use-value を resource の具体的使用における physical realization、labor を interval activity、exchange-value を comparative representation、surplus を required K を超える residual resource / freedom として再配置する。

Marx 固有の labor-value theory / surplus-value theory は socially necessary labor time、production relation 等の追加条件を持つ specialization とする。

---

## 2. Sen / Capability Approach

Capability Approach は、保有 resource や realized utility だけでなく、何を実現しうるかという substantive freedom / capability set を重視する。

VFT の `A_(t+1)` は、これと構造的な接続を持つ。

```text
resource / capability
→ future feasible activities
→ A_(t+1)
```

ただし VFT は個人厚生に限定せず、企業、国家、platform 等の actor / field にも future activity viability / range を適用する。

反復 surplus が生む abstract degree of freedom も、この接続を検討できる。

---

## 3. Simon / Cyert & March

構造的接続：

- 単一目的最大化を前提にしない
- bounded consideration / availability
- aspiration / threshold
- 複数目標の競合
- realized outcome による次期判断の更新

VFT の、

```text
Γ^feas
→ Γ^avail
→ Γ^adm
```

および3つの管理合理性との比較が可能である。

VFT は特定の satisficing rule を Core として固定しない。

---

## 4. managerial theories of the firm

Baumol、Marris 等の managerial theory は、profit maximization 以外に sales、growth、firm size 等の拡張目標と存続制約を置く。

VFT では sales / growth を universal purpose とせず、より一般的に、

```text
A_(t+1) の維持・拡張
```

として配置できる。

market share、transaction volume、user activity 等は projection-specific proxy となる。

---

## 5. Anthony / management control

3合理性と management function には、次の構造的対応がある可能性がある。

```text
A_(t+1) expansion
→ strategy / direction / domain expansion

P-downside
→ management control / protection / allocation

resource-realization
→ operational control / plan realization
```

これは組織階層が必ず3段になるという主張ではない。

異なる合理性が大規模組織で別責務として分化しやすいことの外的妥当性として扱う。

---

## 6. North / Coase 系制度経済学

制度、契約、権利、rule が interaction の成立条件を規定し、不確実性や摩擦を抑えるという構造と接続する。

VFT では、

```text
institutional A / relation
→ P stabilization / feasibility
→ broader A
```

として再配置できる。

制度カテゴリーそのものを primitive とせず、K / P / A / field relation から記述する点が VFT 側の一般化である。

---

## 7. Keynes 系 expectation

期待と実現、生産、需要、投資の連関は、VFT の P / expected ΔK / realized ΔK と接続する。

```text
P
→ expected outcome
→ A
→ realized ΔK
→ P update
```

resource-realization は expected ΔK と realized ΔK の予実一致として、expectation / realization gap と比較できる。

---

## 8. Minsky / financial instability

信用拡張が activity を広げる一方、失敗時の downside を増幅する構造と接続する。

```text
credit expansion
→ broader P-supported relations
→ A expansion
→ larger possible |ΔP^-|
```

VFT では金融固有の法則としてではなく、P を利用して A を先行拡張する一般構造の specialization として扱える。

---

## 9. Control theory / System Dynamics

形式的には、

- state / stock と flow / activity の区別
- expected / target と realized outcome の差
- feedback による次期状態更新

を共有する。

```text
K / P
→ A
→ ΔK
→ X
→ P'
```

ただし VFT は target tracking だけを合理性とせず、`A_(t+1)` expansion と P-downside を独立に保持する。

---

## 10. REA accounting ontology

REA の resource / event / agent を ledger representation より基礎に置く考え方とは構造的類似がある。

VFT では、

- K / K_i：resource state
- actor
- A_i：actor-side event / process
- shared event reconciliation

を持つ。

formal accounting は Core ではなく projection とする。

REA との具体的な共通点・差分は今後整理する。

---

## 11. 継承しない / Core に固定しないもの

既存理論との接続を整理する際、以下は VFT Core の universal rule としない。

- utility maximization
- profit maximization
- general equilibrium
- Marxian labor-value / surplus-value theory
- B/S・P/L・double-entry bookkeeping
- deterministic choice function
- 特定の corporate / state / currency institution

既存理論との関係は、**部分構造の継承・一般化・再配置・specialization** として記述する。
