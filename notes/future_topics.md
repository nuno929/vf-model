# 価値場理論 — 拡張・再検討ノート

> この文書は Core 定義ではなく、今後の形式化・実証・拡張候補を保存する。以下は PR の成立条件ではなく、必要に応じて後続研究で具体化する項目である。

---

## 1. K / K_i

現行 Core では、K は resource / capability state、K_i は actor-specific resource state とする。

今後の検討候補：

- standard resource coordinates
- physical resource と capability の境界
- actor attribution / ownership / access rule
- overlapping / joint attribution
- heterogeneous K に対する `δ_K`
- exogenous change `Ω` の標準化要否

---

## 2. 使用価値

現行 Core では、use-value を resource が use / consumption A を通じて物理的に実現される側として扱う。

今後の検討候補：

- resource-specific realized-use quantity の標準 schema
- machine / infrastructure 等の utilization measure
- durability / repeated use の扱い
- physical realization と subjective utility を併用する projection
- Marxian use-value とのより厳密な比較

---

## 3. surplus / degree of freedom

現行整理では、required K を超える surplus が反復的に生成されることで future A に対する abstract degree of freedom が生まれる。

今後の検討候補：

- required K の operational definition
- surplus persistence の測定
- surplus と action-space expansion の定量関係
- resource-specific freedom から money-mediated freedom への変換
- surplus retention / consumption / reinvestment の動学

---

## 4. P / X

P は未実現 relation / outcome に対する credit / reference state、X はそれを支える observable proxy とする。

P の真値・内部構造・次元は不明とし、金融・経済 projection では必要に応じて scalar `P̂` に近似する。

今後の検討候補：

- P の empirical proxy
- scalar approximation `P̂` の推定法
- shared P の推定
- proxy set X の増加・下方硬直性
- forecast calibration と P update
- policy / institution による `A_F → ΔP_i` の因果識別
- P downside の empirical criterion

---

## 5. field / action sets

今後の検討候補：

- field boundary
- actor-resource graph
- `Γ^feas / Γ^avail / Γ^adm` の formalization
- overlapping fields
- field formation / dissolution
- organization / market / platform / institution の field representation

---

## 6. preference / expected ΔK

Core では、candidate A から actor-specific preference / expectation を通じて expected ΔK を形成する構造だけを置き、普遍的な関数形は固定しない。

必要に応じて検討する候補：

- production / consumption / labor / investment / career choice を同じ形式で記述する場合の coordinate design
- expected ΔK の distributional representation
- preference と forecast の empirical separation

---

## 7. 3つの管理合理性

現行整理：

```text
resource-realization
= expected ΔK と realized ΔK の予実一致

activity-flow
= A_(t+1) の維持・拡張

P-downside
= 将来 A を支える P の重大な毀損回避
```

必要に応じて検討する候補：

- 3合理性の正式名称
- 独立性 / 非還元性の検証
- `A_(t+1)` の operationalization
- rationality trade-off の empirical test
- actor / role / hierarchy 間の機能分担
- crisis / stagnation を3合理性競合として検証する方法

---

## 8. organization / management

3合理性と strategy / management control / operation の機能分化には構造的対応がある可能性がある。

今後の検討候補：

- historical organization structure との比較
- organization size と functional differentiation
- KPI / proxy 数の増加と bureaucratization
- proxy の増えやすさ / 減りにくさ
- purpose complexity と process complexity の識別

---

## 9. money / banking / finance

今後の検討候補：

- money を surplus exchangeability の保存として形式化する方法
- currency field と state field の境界
- deposit / credit P の empirical proxy
- credit expansion と `A_(t+1)` expansion
- leverage / credit と P downside amplification
- banking / payment network の field representation

---

## 10. capital / accumulation

現行整理では capital を独立した一義的 primitive として置かない。

- actual / realized capital side：K
- future value を含む capital valuation：K を基礎に P を含む projection
- book / market / enterprise value：valuation / accounting representation
- surplus reinvestment：capital accumulation / formation

今後の検討候補：

- machine / human / financial capital の projection 上の比較
- reinvestment threshold
- capital accumulation と field expansion
- surplus consumption と accumulation の分岐
- depreciation / obsolescence を含む循環

---

## 11. institution / state / platform

今後の検討候補：

- institutional A と P stabilization
- `A_F → ΔP_i` の強度・持続性
- state / religion / platform の構造比較
- sanction / guarantee / certification / ranking の共通形式
- field-managing actor の定義
- state / currency / platform field の overlap
