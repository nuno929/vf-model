# 価値場理論 — 拡張・再検討ノート

> この文書は Core 定義ではなく、今後の展望・具体化候補・再検討事項を保存するためのノートである。

## 1. 集約と分布化

Core では、K は共通の実資源世界、`K_i` は主体ごとのアクセス可能範囲、`P_i` / `A_i` は主体ごとの状態・行動として扱う。

今後の検討候補：

- どの条件で分布化が有効か
- 平均・代表主体で失われる情報
- 多峰性・非対称性
- ネットワーク構造をどこまで残すか
- 集約後の ΔK / ΔP が何を代理しているか
- 共有資源・重複アクセスの扱い

---

## 2. K の表現粒度

K は共通の実資源世界である。

未解決なのは K が共通かどうかではなく、応用ごとにどの資源成分を保持し、どのように `K_i` へ切り出すかである。

検討候補：

- K の標準次元を設けるか
- 物理資源、時間、技能、情報、関係、権利等の分解
- `K_i` のアクセス可能性の操作化
- 共有・排他的アクセスの表現
- 資本概念との対応

---

## 3. P の表現粒度

P は主体ごとの期待形成状態として Core で定義済みである。

今後の検討候補：

- P の標準次元を設けるか
- 特定応用でどの期待・評価・信用・信念を抽出するか
- P proxy の操作化
- 同一 observable が K / P の両方に関係する場合の識別
- 対象・時間軸ごとの分解

P 固有の普遍的な減衰率・時間定数・更新関数を VFT 側で新たに定義すること自体は未解決事項とはしない。

---

## 4. ΔK / ΔP の型と操作化

Core では ΔK / ΔP を区間状態変化として扱い、すべての成分へ同一のベクトル空間や加法構造を要求しない。

今後の検討候補：

- 各応用で始点・終点を比較可能にする表現
- 加法表現を採用できる条件
- 非加法成分の差分記述
- 共有資源変化と `K_i` 変化の対応
- ΔP proxy の測定誤差

---

## 5. 期待区間変化 E[ΔK]

`E_i[ΔK]` は、主体 `i` が `K_i` / `P_i` から形成する期待区間変化として Core で区別済みである。

今後の検討候補：

- 期待対象と時間窓
- どの K 成分を期待評価へ入れるか
- 期待形成モデルの選択
- 確率的期待値と定性的 forecast の接続
- 実測可能な expectation survey 等との対応

---

## 6. 経済均衡射影の操作化

VFT はミクロ／マクロ均衡を独自の普遍則として定義しない。

今後の検討対象は、具体的な既存経済理論への接続である。

- `E_i[ΔK]` と A をどのミクロモデルへ射影するか
- 政策 A → ΔP_i の経路をどのマクロモデルへ射影するか
- 前区間資源変化と当期期待形成変化の関係を扱うモデル選択
- 射影ごとの time horizon

これらは「ミクロ／マクロは一般にこうである」という VFT 固有の定義ではない。

---

## 7. 期待総余剰の操作化

期待総余剰への射影は、交換・合意によって異種資源間の比較可能性が成立し、一定範囲の資源差分を集約できる場合に限定する。

今後の具体化候補：

- 比較可能性を成立させる交換・合意条件
- 十分な規模の資源差分の定義
- 会計範囲
- 主体間移転の相殺境界
- 共有資源・重複アクセスの扱い
- 必要な換算規則
- 標準経済学上の surplus 指標との対応

---

## 8. A の観測と順序

A の外部 action event は直接観測できる場合がある一方、内部 decision / observation / interpretation は proxy を要する場合がある。

今後の具体化候補：

- A のイベント単位
- 観測・情報受容を A として扱う操作化
- 区間内イベント順序を保持する条件
- coarse-grained representation の情報損失
- ΔK / ΔP がどの範囲の A を代理するか
- A と結果 proxy の時間遅延

`ΔK` / `ΔP` は A を一意に同定する量ではない。

---

## 9. 微小・非主体的な P 変化

Core では、A を P 変化の主要な主体的経路として扱う。

記憶減衰等の微小・非主体的な P 変化は存在しうるが、観測可能な A や P proxy に意味のある差を生じない限り、Core の独立経路として明示モデル化しない。

特定応用で必要になった場合のみ、計測・応用モデル側で追加する。

---

## 10. 組織・国家等の集約主体近似

組織・国家等を単一主体として扱うことは Core 前提ではない。

必要な場合は近似として導入し、

- 対象主体
- 共通 K の対象範囲
- 各主体の `K_i`
- 各主体の `P_i`
- A の集約方法
- 情報損失
- 内部対立

を明示する。

---

## 11. 実証・計量化

今後の具体化候補：

- 共通 K の観測設計
- `K_i` のアクセス可能性
- P proxy
- K / P 識別
- A の直接観測と潜在 decision の proxy
- ΔK / ΔP の結果 proxy 設計
- `E[ΔK]` の推定
- 集約規則
- 測定誤差・欠測
- ケーススタディ
- 反実仮想設計
