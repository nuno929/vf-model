# 価値場理論 — 背景と整理の経緯

> この文書は理論コアではなく、価値場理論が現在の K / P / A 構造へ至るまでの整理経緯を保存するための履歴ノートである。以下に登場する X / V 等は過去の検討段階の変数であり、**現行 Core では独立変数として用いない**。

## 1. 発想の出発点

価値場理論は、社会・経済・組織・個人の変化を、既存分野ごとの語彙に閉じず、同じ構造で記述できないかという問題意識から始まった。

初期段階では、次の4変数を骨格としていた。

- **P**：背景構造
- **K**：自由度
- **X**：選好
- **A**：行為

```text
P -> K -> X -> A -> K -> P
```

この段階の目的は、行為が一方向に生じるのではなく、背景・資源・選好・行為が相互に更新されるという循環構造を明示することだった。

ただし、その後の整理で P / K / X の境界が重複し、独立変数を増やすほど説明が複雑になることが明らかになったため、現行 Core ではこの構造をそのまま採用していない。

---

## 2. K：自由度からアクセス可能な資源へ

初期の K は「自由度」「選択可能域」として定義されていた。

その後、自由度そのものを独立した原始量とするより、**主体が実際にアクセス・利用できる資源・資本が、その主体の行為可能性を規定する**と捉える方が一般的だと整理した。

現行では K を、各アクターがアクセス・利用可能な多次元の実質側 stock とする。

候補には、金銭・設備だけでなく、時間、身体、技能、知識、情報、関係、権限、制度上利用可能な手段等を含む。

自由度は K から独立した変数ではなく、K と対象環境の関係から成立する行為可能性として読む。

また、K はアクターごとに異なる。社会や組織が同じでも、資源・権限・情報へのアクセス可能性が異なれば `K_i` は一致しない。

---

## 3. P：背景構造から期待形成側 stock へ

P は議論の中で最も意味が変化した概念である。

初期には、制度・文化・環境等をまとめた「背景構造」として置いていた。その後、信用、評価、信念、期待、ナラティブ、制度的圧力等が、同じ K のもとでも行動方向を変えることを扱うため、P を名目・期待側の構造として整理した。

さらに、P を単純な「期待値」とみなすと、特定時点・対象について形成される期待値 `E[ΔK]` と混同される問題が生じた。

現行では P を、**各アクターの将来の見通し・評価・選好・信用・信念等を保持し、期待値や行動方向を形成する多次元 stock** とする。

P を「期待 stock」と呼ぶ場合も、期待値そのものを蓄積した量という意味ではない。将来価値への期待や行動を**生成する側の蓄積構造**に注目した呼称である。

P は履歴依存性を持ち、経験や期待の実現結果によって形成・強化・修正される。ただし、経験に裏付けられない初期的な選好・信念・見通しもありうるため、過去履歴だけで完全に決定されるとはしない。

---

## 4. X：独立した選好変数から P への統合

初期モデルでは、P と K の間から生じる主体の選好方向を X として独立に置いていた。

しかし議論を進めると、選好だけを独立した普遍変数として切り出す必要性が薄くなった。

- 選好は主体ごとの P の一部として表現できる
- 将来価値の見込みは `E[ΔK]` として必要な場合のみ明示できる
- 実際の行動方向は K / P の配置から A として現れる

このため、現行 Core では **X を独立変数として置かず、選好差は P の構造差へ統合**している。

---

## 5. V：価値場変数から関係構造へ

途中の検討では、K / P / X 等から価値場の状態を表す独立変数 V を置く案もあった。

しかし、価値場を独立した state として保持すると、K / P と A の間に説明用の中間変数が増える一方、V 自体を直接観測・独立同定する必然性が弱かった。

そこで現行 Core では V を廃止し、価値場を

> **各アクターから見た多主体・多次元の K / P の配置・関係が、それぞれの A に与える方向性**

として定義する。

価値場の「引力」が実現したものを A として扱い、独立した引力量も置かない。

---

## 6. 単一状態から actor-relative / multidimensional へ

初期の記述では K / P / A を単一状態のように読める余地があった。

その後、社会・市場・組織を一主体に還元すると、各主体のアクセス可能性や見通しの差が失われるため、現行では明示的に actor-relative とした。

```text
K_t = {K_i,t}
P_t = {P_i,t}
A_t = {A_i,t}
ΔK_t = {ΔK_i,t}
ΔP_t = {ΔP_i,t}
```

これらの集合記法は確率分布や集約値を意味しない。

K / P は各アクター内でも多次元であり、A は観測区間内に一つ以上存在しうる。必要な場合は A のイベント順序を保持し、粗い時間粒度では順序を捨象した集約表現として扱う。

分布・平均・合計・代表主体等は、存在論ではなく後段の計測・分析操作とした。

---

## 7. K / P の境界整理

P を広い期待形成構造として扱うと、情報・契約・信用等が K / P の双方に見える問題が生じる。

このため現行では、対象物の種類ではなく主体との関係で分ける。

- **K**：主体が実際に利用・行使・参照可能な資源・能力・権利・情報等
- **P**：それらを含む環境について主体が保持する見通し・評価・信用・信念等

例えば、契約上行使可能な権利は K、契約が履行される見込みは P となる。参照可能な情報は K、その情報から形成される将来見通しは P となる。

同じ現象が両側へ影響すること自体は許容するが、同一 observable を理由なく二重計上することは避ける。

---

## 8. ΔK / ΔP と基本動学

理論上の変化を記述するため、K / P の絶対状態だけでなく、それぞれの実現変化を ΔK / ΔP として明示するようになった。

現行では、A は自身または他主体の K / P を変化させうる。

```text
{A_i,t} -> {ΔK_i,t}
{A_i,t} -> {ΔP_i,t}
```

ただし K には、減価償却・老朽化・自然消耗・災害等、A を介さない非主体的変化もありうる。これは独立した普遍変数を追加せず、例外注記として扱う。

P については独立した外生更新を Core に置かない。政策・価格提示・契約条件変更・制度変更等による P への作用も、まず介入主体の A として記述し、その結果として各主体の ΔP が生じると整理した。

---

## 9. P stock と E[ΔK] flow の分離

経済学への射影を整理する中で、P と将来期待値を同一視しないことが重要になった。

特定の主体・対象・時間区間に対する期待実質変化は、

```text
E_i,t[ΔK] = f_i(K_i,t, P_i,t, ...)
```

のように別記する。

P は将来の見通し等を保持する期待形成側 stock、`E[ΔK]` は現在の K / P から特定対象・区間について形成される期待値 flow である。

ただし `E[ΔK]` は A 生成の普遍的な必須中間変数ではない。対象領域で期待値を明示する必要がある場合の射影表現として扱う。

---

## 10. 経済学への射影整理

VFT 独自の均衡則を作るのではなく、既存経済学が持つ均衡・調整過程を K / P / A / ΔK / ΔP / E[ΔK] 上へ射影する方針に整理した。

### ミクロ

各主体の `E_i[ΔK]` と、それに基づく A の相互作用を既存ミクロ経済学の均衡過程へ対応させる。

また、VFTでは消費と供給を別の存在論として置かない。交換範囲内で主体間の単なる K 移転を相殺した後に残る `Σ_i E_i[ΔK]` を、多次元のまま期待総余剰への射影として読む。

これは consumer surplus / producer surplus を独立に定義したものではなく、VFT上の集約的な期待実質変化である。

### マクロ

前区間までに実現した実質側の変化と、当期の政策・市場行動等が誘発する P 側の変化の相互調整を、既存マクロ経済学へ射影する。

金利や通貨供給量を ΔP そのものと同一視せず、政策主体の A とし、それが各主体の P を変え、ΔP を誘発する経路として整理した。

---

## 11. 生成モデルと計測の分離

理論整理の中では、生成過程と観測・逆推定を混ぜないことも重視した。

Core は、

```text
{K_i,t}, {P_i,t}
        ↓
      {A_i,t}
        ↓
{ΔK_i,t}, {ΔP_i,t}
```

という生成構造を記述する。

一方、実証では全てを直接観測できるわけではない。特に `P_i` の全構造は直接観測できるとは仮定せず、個人レベルでは選択・発話・調査等、集約レベルでは価格・金利・信用条件等の名目経済を proxy として使う。

A も原理的には観測可能だが、多数主体・長期間の網羅観測は高コストであるため、必要に応じて ΔK / ΔP を結果 proxy として併用する。

具体的な操作化・集約・識別は Core ではなく Measurement / 応用側へ分離した。

---

## 12. 現行 Core

現在の最小構造は、次のように整理されている。

```text
{K_i,t}, {P_i,t}
        ↓  value field
      {A_i,t}
        ↓
{ΔK_i,t}, {ΔP_i,t}
```

必要な領域では、

```text
(K_i,t, P_i,t) -> E_i,t[ΔK]
```

を期待値 flow として射影する。

現行 Core では、

- X：P へ統合
- V：独立変数として廃止
- 主体間関係 R：普遍的な独立変数として置かない
- 価値場の引力量：独立変数として置かない
- 組織・市場・国家：自動的に単一主体へ還元しない
- K / P / A / ΔK / ΔP：単一スカラーを前提としない

という境界を採用している。
