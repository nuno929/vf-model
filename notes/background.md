# 価値場理論 — 背景と整理の経緯

> この文書は理論コアではなく、議論背景・整理経緯を保存するためのノートである。

## 1. 発想の出発点

価値場理論は、社会・経済・組織・個人の変化を、既存分野ごとの語彙に閉じず、同じ構造で記述できないかという問題意識から始まった。

初期段階では、次の4変数が骨格として整理された。

- **P**：背景構造
- **K**：自由度
- **X**：選好
- **A**：行為

そして、

```text
P -> K -> X -> A -> K -> P
```

という循環構造を、価値場理論の最小モデルとして置いた。

この初期モデルは、変化が一方向の因果ではなく、行為・資源・期待・背景が相互更新されるという点を明示するための骨格だった。

---

## 2. その後の主要な更新

長期的な議論を通じ、初期の P/K/X/A はそのまま固定するのではなく、役割をより厳密に分ける必要があることが分かった。

### 2.1 K：自由度から資源へ

初期の K は「自由度」「選択可能域」として定義されていたが、その後、より基底的には **主体がアクセス可能な資源**として捉える方が一貫するという整理に進んだ。

ここでいう資源には、金銭・物理設備だけでなく、時間、身体、技能、情報、関係、制度上利用可能な手段などを含む。

自由度は K と独立した実体ではなく、K と外部条件によって決まる可到達性として理解する。

### 2.2 ΔK の中心化

理論上の変化を考える際、K の絶対量だけでなく、**何が実際に変化したか**を表す ΔK が中心になった。

行為 A は資源状態を変換し、その結果として ΔK を生む。

```text
A : K_t -> K_{t+1}
ΔK_t = K_{t+1} - K_t
```

この整理によって、成長、損失、外部性、階層間波及などを同じ変化量として扱いやすくなった。

### 2.3 P：背景構造から場へ

P は議論の中で最も意味が動いた概念である。

初期には制度・文化・環境などの「背景構造」をまとめていた。その後、信念、期待、信用、評価、ナラティブ、制度的圧力など、**行為の方向づけや同じ ΔK の解釈を変える非資源的な場**として整理されていった。

そのため現在は、P を単一の物質的背景変数として固定せず、観測スケールに応じた期待・信念・制度・信用の場として扱う。

### 2.4 X：単一効用から多元方向へ

X は単一の合理的効用を表すものではない。

人間は時間・身体・注意の制約により、複数の価値を同時に完全実現できない。そのため、選好はスカラーではなく多元的な方向ベクトルとして扱う方が自然である。

次元間の非整合を許し、完備性や推移性を理論の前提にしない。

### 2.5 A：生成点と観測点

A は価値場理論における主要な観測可能量である。

個人の行為を最小の生成単位とし、組織・社会の行為は、個人行動の集約・調整・再配分・拘束として記述できる。

また、極小時間では X と A は分離できる一方、有限時間では行為系列が選好方向の射影・時間平均として近づくという整理が加わった。

---

## 3. 階層モデルの検討

価値場理論では、個人・組織・社会・文明を扱うために、複数の階層モデルが検討された。

初期には固定4階層を置き、各階層に P/K を持たせる形や、K 自体を K0〜K3 に階層化する形が検討された。

その後、階層は完全に分離した実体ではなく、**観測スケールと内生／外生境界の違い**として理解する方が一般性が高いという整理に進んだ。

---

## 4. 生成モデルと計測理論の分離

理論整理の中で重要になったのが、**生成過程と逆推定過程を混ぜないこと**である。

生成側では、概念上の最小順序を次のように置く。

```text
A -> ΔK -> Observation -> ΔP
```

一方、実際の研究・計測では、直接見えない P や X を観測から逆推定する必要がある。

```text
A / ΔK / C / S / N
        ↓ inference
      X / P / V
```

このため、射影表とは別に計測理論を置く必要がある。

---

## 5. 既存理論との関係

価値場理論の役割は既存理論を否定することではなく、**複数の既存概念を同じ構造へ射影できる上位フレームを与えること**にあるという整理が行われた。

消費 / 供給、効用、資本、外部性、均衡、信用、通貨、国家などを、K / ΔK / P / X / A / V の組み合わせとして再記述する案が検討されている。

これらの具体的な射影はコア定義ではなく、別ノートで扱う。

---

## 6. 応用議論

価値場理論を使った議論では、以下のような応用が検討された。

- 通貨を価値判断同期のプロトコルとして扱う
- 国家を通貨圏・価値同期圏として捉える
- 信用崩壊を、期待ストックと資源制約の同時不成立として扱う
- 国家・組織・個人の違いをスケール差として記述する
- 倫理・大義・功利主義を異なる時間軸の最適化原理として射影する
- 市場を複数アクターの期待・反応・減衰が作る場として扱う

これらは価値場理論のコア定義そのものではなく、射影・応用モデルとして分離する。
