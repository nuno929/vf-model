# 価値場理論 — 計測

## 1. 目的

価値場理論上の `K / P / A / ΔK` は理論変数であり、現実に得られる観測値そのものではない。

計測上の目的は、現実に取得できるデータを **proxy** として用い、対象スケールにおける K / P / A / ΔK を操作化・集計・推定することである。

```text
Observed data O
      ↓ operationalization / aggregation / estimation
K / P / A / ΔK
      ↓
Value-field analysis
```

---

## 2. 観測値は proxy として扱う

価格、数量、取引、資産残高、契約、制度、統計、調査回答、発言、行動ログ等、現実に観測される値はすべて理論変数そのものではなく、理論変数を構成・推定するための proxy として扱う。

たとえば、

- 資産残高や設備量は K の proxy
- 価格、金利、契約、信用指標、評価、調査回答は P の proxy
- 行動ログや取引記録は A の proxy
- 前後時点の複数指標の差は ΔK の proxy

になりうる。

どの観測値をどの理論変数へ対応させるかは、対象領域・観測スケール・時間窓によって異なる。

---

## 3. 直接観測／潜在の固定二分を置かない

価値場理論では、A や ΔK だけを「直接観測」、P だけを「潜在」といった固定的な二分法は採らない。

マクロ経済を含めれば、GDP、資本ストック、期待インフレ等も集計・推計によって構成される量であり、観測値と理論変数の間には常に操作化が入る。

したがって重要なのは、各理論変数について、

1. どの proxy を使うか
2. どの観測スケールで集計するか
3. どの時間窓を使うか
4. どの推定・換算・集約規則を使うか

を明示することである。

---

## 4. K の操作化

K は実質側の資源・資本・自由度を表す stock である。

K の proxy 候補には、

- 所得・資産・現金残高
- 設備・在庫・インフラ
- 時間利用可能量
- 人員・技能・知識
- 利用可能な信用枠
- 実行可能な制度的手段

などがある。

単一の proxy を K そのものと同一視せず、対象領域に応じて必要な成分を構成する。

---

## 5. P の操作化

P は名目・期待側の多次元な期待 stock である。

P の proxy 候補には、

- 価格・金利・スプレッド
- 契約・宣言・公約
- 制度・慣行
- 評判・ブランド評価
- 信用指標
- 調査された期待・信念・評価
- 発言・情報伝播
- 同一対象・同一条件に対する行動差

などがある。

P は対象・主体・観測レイヤーごとに構造も量も異なるため、proxy と集約方法も一律には定まらない。

---

## 6. A と ΔK の操作化

A は資源状態を変換する行為である。

A の proxy 候補には、選択、取引、移動、労働、契約、発言、投資等の記録がある。

ΔK は区間内に実現した実質側の変化であり、前後時点の K proxy を共通の定義で比較することで操作化する。

```text
ΔK_t = K_{t+1} - K_t
```

ただし、実際の計測では K 自体が推定・集計量であるため、ΔK もまた proxy と操作化規則に依存する。

---

## 7. 価値場の計測

価値場は、K / P の推定値そのものではなく、**その配置が行動・資源・流動性の移動方向へどのような引力を生んでいるか**として分析する。

```text
Observed proxies
      ↓
K_hat / P_hat / A_hat / ΔK_hat
      ↓
relation between K and P
      ↓
action / resource-flow attraction
```

価値場の比較では、少なくとも以下を明示する。

1. 観測主体
2. 観測スケール
3. K の構成と proxy
4. P の構成と proxy
5. A の操作化
6. ΔK の計測窓
7. 期待 ΔK の時間窓
8. 集約・推定規則

---

## 8. 期待 stock / flow の区別

P は期待 stock、`E[ΔK]` は期待 flow として分ける。

```text
E_t[ΔK_t] = f(P_t, ΔK_{t-1})
```

`ΔP` を用いる場合、それは P の差分であって期待 flow そのものではない。

期待 ΔK の具体的な推定方法も、対象領域の既存理論・計測方法に従う。

---

## 9. 選好・合理性

選好、好き嫌い、合理性／非合理性を独立した潜在変数として測定しない。

同一対象・同一実質条件に対する行動差は、主体ごとの P の構造差・量的差と、そこから形成される期待 ΔK の差として記述する。

自己申告された好みも P の proxy の一つであり、それ自体を理論変数と同一視しない。

---

## 10. 実証上の原則

価値場理論を実証へ落とす際は、少なくとも以下を明示する。

1. 観測スケール
2. 理論変数ごとの proxy
3. 操作化・換算方法
4. 集約規則
5. 時間窓
6. 欠測・測定誤差の扱い
7. 期待 ΔK の推定方法
8. 価値場の引力を何で評価するか

価値場理論は特定の統計手法や単一の proxy を固定しない。

目的は、**観測データを理論変数そのものと取り違えず、proxy から K / P / A / ΔK を構成し、その関係から行動・流動の引力を記述すること**にある。
