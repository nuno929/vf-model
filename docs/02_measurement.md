# 価値場理論 — 計測

## 1. 目的

本書は、価値場理論の Core を実証・観測へ落とす際の境界を整理する。

Core では、K は共通の実資源世界、`K_i` はそのうち主体 `i` がアクセス・利用可能な範囲、`P_i` は主体ごとの期待形成状態として扱う。

計測上の課題は、K / P / A を一つのスカラーへ還元することではなく、**どの資源、主体、時間窓、proxy、集約規則を観測対象にするかを明示すること**である。

---

## 2. K と K_i の計測

K は共通の実資源世界を参照する。

`K_i` は、その K のうち主体 `i` が実際にアクセス・利用・行使・参照可能な範囲である。

したがって、同じ設備、情報、インフラ、信用制度等が複数主体の `K_i` に関係しうるが、資源自体が主体ごとに複製されたことを意味しない。

K の候補指標には、所得、利用可能な現金、行使可能な金融請求権、設備・在庫・インフラ、時間、人員、技能、知識、情報、利用可能な信用枠、権限・アクセス可能な手段等がある。

金融資源は、名目上の評価額そのものではなく、実際に行動可能性を増やす利用可能な資源・権利として K / `K_i` へ操作化する。

応用では、共通 K のどの成分を観測し、そのうち各主体がどこまで利用可能かを明示する。

---

## 3. P の計測

`P_i` は主体 `i` の将来の見通し・評価・選好・信用・信念等を保持する多次元の期待形成状態である。

個々の `P_i` の全構造を直接観測できるとは仮定しない。

候補 proxy には、調査された期待・信念・選好・評価、発話、契約に対する信用、評判・ブランド評価、価格、金利、スプレッド、信用条件等がある。

価格・金利・信用条件等は P そのものではなく、P の集約的な現れを含みうる observable として扱う。

### 理論変数と observable の分離

`P_i` / `ΔP_i` は理論上の期待形成状態とその変化であり、直接観測できることを Core の要件とはしない。価格、金利、調査値、信用条件、発話等は、それらと K / A / 制度・市場過程等の相互作用から生じる observable / proxy として扱う。

したがって、**理論変数と observable の対応は応用・計測ごとに定める measurement mapping であり、Core が普遍的な観測式を固定するものではない。** P を直接観測できないこと自体は、P を理論変数として置くことと矛盾しない。

---

## 4. K / P の識別原則

K / P は対象物の種類だけで分類しない。

- **K**：実際に存在し、主体が利用・行使・参照できる資源・能力・権利・情報等
- **P**：それらを含む環境について主体が保持する見通し・評価・信用・信念等

例：

- 契約上行使可能な権利 → K
- 契約が履行される見込み → P
- 参照可能な情報 → K
- その情報から形成された将来見通し → P

同一 observable を根拠なく K / P の双方へ二重投入しない。両側に関係する場合は、何を実利用可能性として測り、何を主体内の期待形成状態として測るかを分ける。

---

## 5. A の観測可能性

A は各主体の行動・意思決定を表す。

外部に実現した action event は直接観測できる場合がある。取引、移動、発話、投資、労働、契約、政策変更等が該当する。

一方、内部の意思決定、観測、情報受容、解釈等は直接観測できない場合があり、proxy を要する。

観測・情報受容・解釈を A に含める場合も、それらが必ず能動的行為であることを意味しない。P 更新を記述する actor-side process として必要な範囲で含める。

同一区間内の順序が重要な場合はイベント順序を保持する。粗い時間粒度では順序を捨象した coarse-grained representation として扱う。

---

## 6. ΔK / ΔP の観測

対象範囲 `S` と時間区間 `τ` を明示した実資源差分を `ΔK(S, τ)` とする。

`ΔK(S, τ)` は、**対象範囲 `S` について時間区間 `τ` 内に実現した実資源量の差分（総量変化）**を表す。`ΔP_i` は主体 `i` の P に実現した区間差分を表す。

文脈上 scope が明らかな場合は `ΔK(S, τ)` を `ΔK` と省略する。

加法表現が適用できる場合には、

```text
K_t+1 = K_t + ΔK_t
P_i,t+1 = P_i,t + ΔP_i,t
```

と書ける。

ただし、すべての K / P 成分へ同一のベクトル空間や加法構造を要求しない。応用ごとに、同一対象について観測区間の始点・終点を比較可能にする。

`ΔK` はミクロ用・マクロ用に別の型へ分けない。個人の消費・生産に対応する資源差分も、複数主体・市場・長期区間で集約された資源差分も、対象主体・時間・資源範囲のスケールが異なる同じ `ΔK` として計測する。

`ΔK` / `ΔP` は A の結果 proxy として使える場合があるが、複数の A が相殺・重複しうるため、A を一意に同定する量ではない。

K には減価償却・自然損耗等、A 非経由の変化もありうるため、`ΔK` を A の proxy として使う場合は必要に応じて考慮する。

---

## 7. P の変化と観測

A は P を変化させる主要な actor-side process である。

政策変更、価格提示、契約条件変更、情報伝達、観測・情報受容・解釈等による P の変化も、必要に応じて A を介する経路として記述できる。

記憶減衰等の微小・非主体的な P 変化の存在自体は否定しない。ただし、それが観測可能な A や P proxy に意味のある差を生じない限り、Core の主要変化経路として明示的に操作化しない。

実証で非主体的な P 変化を扱う必要がある場合は、対象領域の計測モデル側で追加する。

---

## 8. E[ΔK] の位置づけ

主体 `i` が、自らの消費・生産等として関与する対象範囲 `S`・時間区間 `τ` について形成する期待実資源変化を `E_i[ΔK(S, τ)]` とする。

```text
E_i,t[ΔK(S, τ)] = f_i(K_i,t, P_i,t, ...)
```

期待値評価に用いる K は、主体 `i` が実際に利用可能な `K_i` とすることができる。

ここで actor-relative なのは、期待評価に入る資源範囲、`P_i`、およびそこから形成される期待値である。期待対象である `ΔK(S, τ)` 自体を主体別の別資源変数へ分けない。

文脈上 scope が明らかな場合は `E_i[ΔK(S, τ)]` を `E_i[ΔK]` と省略する。

`E[...]` は expectation operator として、対象となる K の差分が quantitative projection 上で表現され、期待値が定義可能な場合に用いる。非加法的・非数量的な K 成分について数量的な期待値を用いる場合は、対象応用で quantitative projection を先に定める。数量化しない forecast は別途定性的に記述し、無理に `E[...]` としない。

`E[ΔK]` は rate としての flow ではなく、**expected interval change / 期待区間変化**として扱う。

`E[...]` は主体が形成する見込み値・期待値を表し、主体の望みそのものではない。選好・望ましさ・評価は P に保持され、期待形成に影響する。

具体的な推定方法は対象領域の既存理論・計測方法に従う。

---

## 9. 集約

VFT は、複数主体の `K_i` / `P_i` / `A_i` を自動的に一主体・一変数へ集約しない。

集約する場合は少なくとも以下を明示する。

1. 共通 K の対象範囲
2. 対象主体集合
3. 各主体の K へのアクセス範囲
4. P に用いる proxy
5. A の観測単位とイベント順序
6. 時間窓 `τ`
7. 資源 scope `S`
8. ΔK / ΔP の集約規則
9. 共有資源・重複アクセスの扱い
10. 情報損失
11. 各 proxy が何を代理しているか

分布、平均、比率、指数、代表主体等はこの後段で導入する分析表現であり、Core の存在論ではない。

ミクロからマクロへの接続でも、新しい `ΔK_macro` の型を置く必要はなく、対象主体・時間・資源範囲を広げた `ΔK` の集約として扱う。

---

## 10. 経済射影での集約

比較可能な資源差分について主体別期待を単純和する場合、

```text
Σ_i E_i[ΔK]
```

はまず **aggregate expected resource change** として扱う。

この集約は、互いに無関係な actor-relative ベクトルを無条件に加算することを意味しない。対象とする共通 K の範囲、対象主体集合、期待資源差分の比較可能性、会計・換算規則、共有資源・重複アクセス、scope / horizon の整合性を明示する。

標準経済学上の consumer surplus / producer surplus / total surplus と対応づける場合は、対象理論側で valuation、utility、WTP / WTA、cost 等との measurement mapping を追加する。VFT は `Σ_i E_i[ΔK]` を無条件に標準経済学上の total surplus と同一視しない。

---

## 11. 需要・供給射影の条件

`E_i[ΔK]` 自体は demand / supply の定義ではない。

時間幅や対象主体数を拡張した aggregate expectation を需要・供給構造へ射影する場合は、少なくとも以下の仮定を検討する。

- P の持続的成分が観測区間に対して十分安定しているか
- 個別変動が独立または弱依存とみなせるか
- 共通ショックが支配的でないか
- herd behavior / network dependence が集約を歪めないか
- regime change により期待形成構造自体が変化していないか

これらの条件が満たされない場合、区間幅や母数を増やしても個別ノイズが単純に相殺されるとは限らない。また horizon を長くすること自体が不確実性を増幅する場合もある。

したがって、需要・供給への接続は **projection-specific な条件付き解釈**として扱う。

---

## 12. 実証上の原則

価値場理論を実証へ落とす際は、少なくとも以下を明示する。

1. 観測スケール
2. 共通 K の対象範囲
3. 各主体の K へのアクセス範囲
4. P に用いる proxy と対象範囲
5. K / P の識別原則
6. A を直接観測する範囲
7. 内部 decision / observation の proxy
8. ΔK / ΔP を結果 proxy として使う範囲
9. 理論変数と observable の measurement mapping
10. scope `S`
11. horizon `τ`
12. 集約規則
13. 欠測・測定誤差
14. `E[ΔK]` を適用する quantitative projection
15. `E[ΔK]` の推定方法
16. 需要・供給へ射影する場合の依存構造・安定性条件

目的は、**共通の実資源世界 K と、主体ごとのアクセス範囲 K_i・期待形成状態 P_i・期待区間変化 E_i[ΔK(S, τ)] を混同せず、同じ ΔK を観測スケールに応じて集約し、A / ΔP / proxy と使い分けること**にある。
