# 価値場理論 — 計測理論

## 1. 目的

射影表は、既存概念を価値場理論のどこへ置くかを決める。

しかし、それだけでは「その概念を何から観測・推定するか」が決まらない。

価値場理論では、コア変数のうち直接観測可能なものと、観測から逆推定する潜在変数を分ける。

---

## 2. 観測と潜在変数

### 直接観測の中心

| 記号 | 観測対象 | 例 |
| --- | --- | --- |
| **A** | 行為 | 選択、発話、取引、移動、労働、契約 |
| **ΔK** | 行為前後の資源差分 | 所得変化、時間消費、在庫変化、関係変化、能力獲得 |
| **C** | 条件 | 制度、価格、契約、物理環境、市場条件 |
| **S** | 自己申告 | 意図、満足、期待、評価、理由 |
| **N** | 補助的な生理・神経等の観測 | 必要な研究でのみ利用 |

### 主な逆推定対象

| 記号 | 潜在対象 | 何を表すか |
| --- | --- | --- |
| **X** | 選好方向 | どの方向へ動こうとしているか |
| **P** | 場 | 何を期待し、どう解釈し、どの方向へ配向されるか |
| **V** | 価値場表現 | 行為・変化が生じやすい方向、圧力、勾配 |

---

## 3. 生成と推定を分ける

### 生成モデル

```text
K / P / X / C
      ↓
      A
      ↓
     ΔK
      ↓
 Observation
      ↓
     ΔP
```

### 計測モデル

```text
A / ΔK / C / S / N
        ↓
     inference
        ↓
      X / P / V
```

この2つを混同すると、観測値と潜在概念が同一視される。

例えば、自己申告された「好み」は X そのものではなく、X を推定するための S の一つである。

---

## 4. X の計測

X は直接観測しない。

推定には、少なくとも次の情報を組み合わせる。

- 行為系列 A
- 行為前後の ΔK
- 選択肢集合・制度・価格等の C
- 自己申告 S

概念的には、

```text
X_hat = I_X(A_{1:T}, ΔK_{1:T}, C_{1:T}, S_{1:T})
```

と置く。

単一時点の発話や選択だけで X を確定しない。

また、X は多元ベクトルであるため、単一の効用スカラーに強制的に還元する必要はない。

---

## 5. P の計測

P も直接観測しない。

P の候補観測には、

- 契約・宣言・公約
- 市場価格・信用スプレッド
- 評判・ブランド評価
- 制度・慣行
- 自己申告された期待・信念
- 同一 ΔK に対する異なる反応

などがある。

概念的には、

```text
P_hat = I_P(A, ΔK, C, S, market/network observations)
```

と置く。

P は観測スケールによって構成が変わるため、個人・組織・社会で同じ指標を使う必要はない。

---

## 6. V の計測

V は原始変数ではなく派生表現である。

そのため、V を直接測定するのではなく、推定した K / P / X と条件 C から導出する。

```text
V_hat = G(K_hat, P_hat, X_hat, C)
```

V の具体形は応用ごとに定義する。

---

## 7. 概念境界

### 選好

選好は自己申告そのものではない。

```text
S != X
```

S は X 推定の一観測である。

### 制約

制約は、観測上まず「可到達な行為集合の縮小」や「ΔK の発生可能性の変化」として現れる。

```text
C / P -> ReachableActions(K, C) -> A / ΔK
```

その原因を制度的 P に帰属するか、物理的 C や資源 K に帰属するかは、観測設計で識別する必要がある。

### 外部性

外部性は、ある主体 i の行為が別主体 j の資源変化を生む構造として定義できる。

```text
A_i -> ΔK_j   (i != j)
```

正負の価値判断を先に置く必要はない。

### 信用

信用は K そのものではない。

現在利用可能な信用枠が実際の可到達性を増やす場合は K に反映される一方、その信用を支える将来期待・評価は P として推定する。

---

## 8. 時間順序

価値場理論では、結果と意味更新を同一時点の一変数として潰さない。

概念上、

```text
A_t -> ΔK_t -> O_t -> ΔP_t
```

と分ける。

この分離により、

- 実際に何が起きたか
- それがどう観測されたか
- その結果、期待・信用・信念がどう更新されたか

を別々に扱える。

---

## 9. スケールの計測

個人・組織・社会は同じ変数名を使えても、観測単位が異なる。

### 個人

- A：個人行動
- ΔK：時間、所得、健康、技能、関係等の変化
- P：期待、信念、信用、所属規範等

### 組織

- A：個人行動を集約した意思決定・取引
- ΔK：予算、人員、設備、契約、知識等の変化
- P：信用、ブランド、組織慣行、契約期待等

### 社会

- A：個人・組織行動の分布・集約
- ΔK：インフラ、技術、制度上の実行余地、資源分布等の変化
- P：市場期待、制度信認、社会規範、ナラティブ等

階層そのものを実体化せず、**観測窓と集約規則を明示すること**が重要である。

---

## 10. 実証上の原則

価値場理論を実証へ落とす際は、少なくとも以下を明示する。

1. 観測スケール
2. K の成分
3. A の単位
4. ΔK の計測窓
5. C と P の識別条件
6. X / P / V の推定方法
7. 集約規則

価値場理論の計測理論は、特定の統計手法を固定するものではない。

目的は、**何を直接観測し、何を逆推定するかを固定すること**にある。

反実仮想・動学的損失などの追加計測テーマは [拡張・再検討ノート](../notes/future_topics.md) で扱う。
