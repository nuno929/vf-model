# 価値場理論 — モデルノート

## 1. 目的

本ノートは、価値場理論のコア変数と基本動学を、READMEより形式的に整理する。

ここで扱う中心変数は、

- `K`：資源状態
- `ΔK`：実現した資源変化
- `P`：将来の行動・結果に対して形成される期待構造
- `X`：潜在的な選好方向
- `A`：行為
- `V`：これらから導く価値場の方向・圧力・勾配表現

である。

重要なのは、**存在論・生成過程・計測過程・射影を混ぜないこと**である。

---

## 2. K：多元資源状態

K は単一量ではなく、多元ベクトルとして扱う。

```text
K_t = (K_1, K_2, ..., K_n)_t
```

成分は対象に応じて異なる。個人なら時間・健康・技能・所得・情報・関係、組織なら人材・予算・設備・技術・契約余地、社会ならインフラ・技術・制度上の実行余地などが候補となる。

K の重要な性質は、主体の**可到達な行為集合**を制約することである。

```text
ReachableActions_t = R(K_t, C_t)
```

ここで C は物理・制度・契約等の観測可能条件を表す。

「自由度」は K の別名というより、この可到達集合の大きさ・形として導出される。

---

## 3. A と ΔK

A は資源状態を変換する作用として扱う。

```text
A_t : K_t -> K_{t+1}
```

したがって、

```text
ΔK_t = K_{t+1} - K_t
```

を実現差分とする。

より一般には、行為 A、現在の資源 K、条件 C、場 P のもとで、

```text
ΔK_t = F(A_t, K_t, P_t, C_t) + ε_K
```

と書ける。

ここで F の具体形は分野ごとに異なるため、コア理論では固定しない。

---

## 4. P：期待構造

P は、**将来の行動・結果に対して個人または社会的に形成される期待構造**である。

信用、評価、契約、制度、慣行、公約、PR、ナラティブ等は、それぞれ拘束力・共有範囲・持続性は異なるが、将来に対する期待を形成・固定・伝播する P の形態として扱う。

P は実現した ΔK そのものではなく、実体変化と独立に介入・形成されうる。制度についても、その制度が将来どのように作用するかという期待構造は P に含まれ、実際に生じた資源状態の変化は K / ΔK 側に現れる。

P は単一主体の内部状態だけを意味しない。観測スケールに応じて、個人の期待から、市場・組織・制度として共有された期待構造までを扱う。

P は直接観測される原始量ではなく、複数観測から推定される潜在場として扱う。

---

## 5. ΔK の期待値

次区間の実体変化に対する期待値は、現在の P と前区間の実現値 ΔK から形成される。

```text
E_t[ΔK_t] = f(P_t, ΔK_{t-1})
```

ここで、

- `P_t`：将来の行動・結果に対して形成された期待構造。契約・宣言・信用・金融・PR 等を通じて実体変化と独立に介入可能
- `ΔK_{t-1}`：前区間に実際に実現した資源変化
- `E_t[ΔK_t]`：現在時点で形成される次区間の実体変化の期待値

である。

P は `E[ΔK]` そのものではない。P と前期実績 ΔK の双方を材料として、実体側の期待値が形成される。

必要に応じて複数期の履歴を含めることはできるが、コアでは上記の最小形に留める。

---

## 6. ΔP：観測後の更新

ΔP は、**結果観測後に生じる期待構造の更新**として扱う。

概念順序は、

```text
A_t
 -> ΔK_t
 -> O_t = Observe(A_t, ΔK_t, C_t)
 -> ΔP_t = U(P_t, O_t)
```

と置く。

したがって、

```text
P_{t+1} = P_t + ΔP_t
```

となる。

必要な分野では外部介入、減衰、慣性等を追加できるが、具体形や係数はコアでは固定しない。

---

## 7. X：多元選好ベクトル

X は主体の行為方向を表す潜在ベクトルである。

```text
X_t = (x_1, x_2, ..., x_m)_t
```

各次元は必ずしも相互整合的でなくてよい。

したがって、価値場理論では以下を一般前提としない。

- 完備性
- 推移性
- 単一効用関数への還元
- 常時一貫した合理的選択

観測された A は、X が K / P / C によって射影されたものとして扱える。

```text
A_t ~ Π(X_t | K_t, P_t, C_t)
```

ここで Π は行為への射影・実装写像である。

X と A の具体的な時間関係や Π の形は、コアでは固定しない。

---

## 8. V：価値場の派生表現

V は P/K/X/A と同列の原始変数ではなく、対象に応じて導出する**方向・圧力・勾配の表現**として扱う。

概念的には、

```text
V = G(K, P, X, C)
```

と置ける。

V を使う目的は、ある状態からどの方向へ行為・資源変化が起こりやすいかを、比較・可視化しやすい座標へ落とすことにある。

具体的な G は応用ごとに定義する。

---

## 9. 生成過程と推定過程

生成過程と推定過程は逆向きである。

### 生成側

```text
K_t, P_t, X_t, C_t
        ↓
       A_t
        ↓
      ΔK_t
        ↓
    Observation
        ↓
      ΔP_t
```

### 計測側

```text
A / ΔK / C / S / N
        ↓ inference
      X / P / V
```

この区別によって、自己申告をそのまま選好 X と同一視することや、観測された制約を即座に P と断定することを避ける。

---

## 10. スケール

個人・組織・社会・文明を、固定された独立世界としてではなく、観測スケールの違いとして扱う。

各スケールで、何を内生化し何を外生条件とするかが異なる。

| スケール | 主な内生対象 | 主な外生条件の例 |
| --- | --- | --- |
| 個人 | 判断・行為・局所資源更新 | 制度・市場・組織 |
| 組織 | 調整・再配分・契約・資源配分 | 市場・法・技術環境 |
| 社会 | 分布・制度・市場構造 | 技術・人口・地理 |
| 文明 | 長期技術・世界観・制度群 | 物理・地理条件 |

あるスケールの内生成果が、別スケールでは外生条件として現れる。

具体的な階層間伝播式・減衰・上下非対称性は、コア定義として固定せず [拡張・再検討ノート](../notes/future_topics.md) で扱う。

---

## 11. コアで固定しないもの

以下は応用・実証・追加議論で決めるべきであり、コアでは固定しない。

- K の標準次元
- P の標準次元
- X の具体的軸
- V の導出関数 G
- 行為射影 Π の具体形
- P 更新関数 U
- 減衰率・時間定数
- 階層間写像
- 資本・均衡・市場等の既存概念との具体対応
- 組織・国家等を一つの主体として扱う近似条件

価値場理論のコアは、これらの係数や応用モデルを先に決めることではなく、**何が直接観測され、何が潜在で、どの差分がどの更新を生むかを明確にすること**にある。
