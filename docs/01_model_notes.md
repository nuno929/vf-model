# 価値場理論 — モデルノート

## 1. 目的

本ノートは、価値場理論のコア変数と基本動学を README より形式的に整理する。

価値場理論は現段階では、K / P から A を一意に予測する普遍的な選択則を与える理論ではなく、**共通の実資源世界、主体ごとの期待形成状態、行動、実現変化を同一の構造で記述する structural framework** として扱う。

---

## 2. K：共通の実資源世界

K が参照する資源世界は主体ごとに別々に存在するのではなく、同一の物理的・社会的な実資源世界を前提とする。

```text
K_t
```

K は多次元であり、時間、身体、技能、知識、情報、関係、設備、資金、インフラ、権利、制度上利用可能な手段等を含みうる。

一方、各主体がその全てへ同じようにアクセスできるわけではない。主体 `i` が時点 `t` に実際にアクセス・利用・行使・参照可能な範囲を `K_i,t` とする。

```text
K_i,t = actor i が K_t から利用可能な範囲・状態
```

`K_i` は主体ごとに別の資源世界を意味しない。共通 K の actor-relative な切り出しである。同じ設備、公開情報、インフラ等が複数主体の `K_i` に関係しうるが、資源そのものが複製されたことを意味しない。

---

## 3. P：期待形成側の stock

各主体 `i` の `P_i,t` は、**将来の見通し・評価・選好・信用・信念等を保持し、期待値や行動を形成する多次元の期待形成状態**である。

```text
P_t = {P_i,t}
```

P を「期待 stock」と呼ぶのは、P 自体を特定時点の期待値とみなすためではない。**将来価値への期待や行動を生成する側の蓄積構造であることに着目した呼称**である。

P は履歴依存性を持ち、過去の期待、その実現結果、信用、評価、制度、経験等を通じて形成・強化・修正されうる。ただし、経験に裏付けられない初期的な選好・信念・見通しもありうるため、過去履歴だけから完全に決定されるとはしない。

信用、評価、契約、制度、慣行、公約、PR、ナラティブ等は、各主体の P の形成・固定・伝播に影響しうる。

---

## 4. K / P の境界

K / P は対象物の種類だけで分類しない。

- **K**：実際に存在し、主体が利用・行使・参照できる資源・能力・権利・情報等
- **P**：それらを含む環境について主体が保持する見通し・評価・信用・信念等

例えば、契約上行使可能な権利は K、契約が履行される見込みは P となる。参照可能な情報そのものは K、その情報から形成される将来見通しは P となる。

同じ現象が K / P の双方へ影響することはありうるが、同一 observable を根拠なく二重計上しない。

---

## 5. A：行動・意思決定

A は単一の社会的行為ではなく、各主体の行動・意思決定を表す。

```text
A_t = {A_i,t}_{i in I}
```

各 `A_i,t` は、主体 `i` が観測区間内に行った一つ以上の行動・意思決定を含みうる。観測、情報受容、解釈等、P を更新する主体的処理も必要に応じて A に含める。

区間内で `A_1 -> state change -> A_2` のようなフィードバックが重要な場合はイベント順序を保持する。粗い時間粒度では、順序を捨象した coarse-grained representation として扱うことができる。

組織・市場・社会を扱う場合も、必要がない限り複数主体の A を一つの主体行動へ還元しない。

---

## 6. 価値場

価値場は、**共通の K、その主体が利用可能な K_i、および各主体の P の配置・関係が、各 A を条件づけ、特定の行動を生じやすく／生じにくくする構造**である。

```text
K_t
├─ K_1,t
├─ K_2,t
└─ ...

{K_i,t}, {P_i,t}
        ↓  value field
      {A_i,t}
```

ここでいう「方向性」「引力」は action space 上の幾何学的ベクトルを意味しない。独立した価値場変数、引力量、普遍的な選択関数は置かない。

他主体や環境について主体 `i` がどう認識・予測しているかは、必要な範囲で `P_i` に含める。別の普遍的観測写像は Core に追加しない。

---

## 7. ΔK / ΔP：状態変化

`ΔK` は共通 K に実現した資源状態の変化、`ΔP_i` は主体 `i` の P に実現した状態変化を表す。

```text
{A_i,t} -> ΔK_t
{A_i,t} -> {ΔP_i,t}
```

`ΔK` / `ΔP_i` は、観測区間の始点と終点で比較可能な表現を採る場合の状態変化である。加法的表現が適用できる場合には、

```text
K_t+1 = K_t + ΔK_t
P_i,t+1 = P_i,t + ΔP_i,t
```

と書ける。

ただし Core が、健康、権利、情報、信念等を含むすべての成分へ同一のベクトル空間や加法構造を要求するわけではない。各応用で、同一対象について区間前後を比較できればよい。

A は K / P を変化させる主要な主体的経路である。政策変更、価格提示、契約条件変更、情報伝達、観測・情報受容等による P の変化も、原則として何らかの主体的 A を介するものとして記述できる。

記憶減衰等の微小・非主体的な P 変化の存在自体は否定しない。ただし、それが観測可能な A や P proxy に意味のある差を生じない限り、Core では独立した変化経路として明示的にモデル化しない。

K には減価償却・老朽化・自然消耗・災害等、A を介さない非主体的変化もありうる。これも独立した普遍変数を追加せず、必要な応用で考慮する。

---

## 8. E[ΔK]：期待区間変化

特定主体・対象・時間区間について主体が望み・見込む実資源変化を `E_i,t[ΔK]` とする。

```text
E_i,t[ΔK] = f_i(K_i,t, P_i,t, ...)
```

期待値評価に用いる K は、主体 `i` が実際にアクセス・利用可能な範囲 `K_i` でよい。**K の存在論自体が主体ごとに相対化されるのではなく、期待評価へ入力される K の切り出しと、そこから形成される期待値が actor-relative である。**

`E[ΔK]` は rate としての flow ではなく、特定対象・区間に対する **expected interval change / 期待区間変化** として扱う。

`E[...]` は主体が持つ期待・予測を表す記法であり、Core が特定の確率分布や期待形成モデルを固定することを意味しない。

`E_i[ΔK]` は期待側の変化量であり、価格、供給能力、時間、制度、他主体の行動等の制約によって、同じ大きさの実現変化 `ΔK` になるとは限らない。

`E[ΔK]` を A 生成の普遍的な必須中間変数とはしない。

---

## 9. 経済学への射影

経済均衡は VFT 固有の普遍則として定義しない。以下は既存経済学への射影候補である。

### ミクロ

各主体の `E_i,t[ΔK]` と、それに基づく A が相互作用する過程を、対象とする既存ミクロ経済学の均衡・調整過程へ対応させることができる。

VFT は需要側と供給側を別の存在論として分離しない。経済射影では、主体が望み・見込む資源変化 `E_i[ΔK]` を期待側、実際に生じた資源変化 `ΔK` を実現側として区別し、その差や調整を需要・供給・均衡過程へ対応させることができる。

交換・合意によって異種資源間の比較可能性が成立し、対象となる主体別の期待変化を同一の集約範囲で比較できる場合、**各主体の `E_i[ΔK]` の集約を期待総余剰（expected total surplus）への射影として扱うことができる。** 単純和を用いる場合は `Σ_i E_i[ΔK]` と表せるが、比較可能性、対象範囲、会計・換算規則、共有資源・重複アクセスの扱いを射影先で明示する。

期待総余剰は実現した共通 K の純増 `ΔK` と同一ではない。主体が望み・見込む期待変化には、各種制約によって実現しない部分がありうる。

### マクロ

政策金利の変更、通貨供給量の操作、制度変更等は、まず政策主体の A として扱う。その A が各主体の見通し・信用条件等へ作用し、`ΔP_i` を誘発する。

前区間までに実現した資源変化と、当期の A が誘発する期待形成側の変化との相互作用を既存マクロ経済学へ対応させることは、一つの射影候補である。ミクロ／マクロ一般の時間構造を VFT が独自に定義するものではない。

Core の K / P を経済学上の real / nominal と同一視しない。K は resource / capability side、P は expectation / valuation side として置き、real / nominal の語は経済学への具体的射影でのみ用いる。

---

## 10. 計測

A のうち外部に実現した action event は直接観測できる場合がある。一方、内部の意思決定、観測、解釈過程は直接観測できず、proxy を要する場合がある。

個々の `P_i` の全構造も直接観測できるとは仮定しない。価格、信用、評価、契約、調査された期待・信念・発話等の観測可能な指標から必要な範囲を proxy として扱う。

集約レベルでは、価格、金利、信用条件等の名目経済指標を、複数主体の P の総体的な現れの proxy として利用できる。ただし `{P_i}` の完全な総和や直接観測を意味しない。

`ΔK` / `ΔP` は A の結果 proxy として利用できる場合があるが、複数の A が相殺・重複しうるため、A を一意に同定する量ではない。

---

## 11. スケール

個人・組織・社会・文明を、固定された独立世界としてではなく、観測スケールと内生／外生境界の違いとして扱う。

組織・国家等を単一主体として扱う場合は近似であり、対象主体、K へのアクセス範囲、P の対象範囲、集約規則、情報損失を明示する。

---

## 12. コアで固定しないもの

以下は応用・実証・追加議論で決める。

- K / P の標準次元
- A の普遍的な選択則
- `E[ΔK]` の普遍的な形成式
- ミクロ／マクロの具体的均衡・調整過程
- K / P / A / ΔK / ΔP の普遍的集約規則
- 階層間写像
- 資本・市場等の既存概念との具体対応
- 組織・国家等を一つの主体として扱う近似条件
- proxy と理論変数の具体的な対応

また、価値場理論は K / P / A を単一スカラーや確率分布として定義しない。
