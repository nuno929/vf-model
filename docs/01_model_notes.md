# 価値場理論 — モデルノート

## 1. 目的

本ノートは、価値場理論のコア変数と動学を、READMEより形式的に整理する。

ここで扱う中心変数は、

- `K`：資源状態
- `ΔK`：実現した資源変化
- `P`：期待・信念・信用・制度的背景等の場
- `X`：潜在的な選好方向
- `A`：行為
- `V`：これらから導く価値場の方向・圧力・勾配表現

である。

重要なのは、**存在論・生成過程・計測過程・射影を混ぜないこと**である。

---

## 2. K：多元資源状態

K は単一量ではなく、多元ベクトルとして扱う。

```text
K_t = (K_1, K_2, ..., K_n)_t
```

成分は対象に応じて異なる。個人なら時間・健康・技能・所得・情報・関係、組織なら人材・予算・設備・技術・契約余地、社会ならインフラ・技術・制度上の実行余地などが候補となる。

K の重要な性質は、主体の**可到達な行為集合**を制約することである。

```text
ReachableActions_t = R(K_t, C_t)
```

ここで C は物理・制度・契約等の観測可能条件を表す。

「自由度」は K の別名というより、この可到達集合の大きさ・形として導出される。

---

## 3. A と ΔK

A は資源状態を変換する作用として扱う。

```text
A_t : K_t -> K_{t+1}
```

したがって、

```text
ΔK_t = K_{t+1} - K_t
```

を実現差分とする。

より一般には、行為 A、現在の資源 K、条件 C、場 P のもとで、

```text
ΔK_t = F(A_t, K_t, P_t, C_t) + ε_K
```

と書ける。

ここで F の具体形は分野ごとに異なるため、コア理論では固定しない。

---

## 4. P：期待・信念・信用・背景の場

P は K とは異なる役割を持つ。

- K：何が実行可能かを規定する
- P：何が期待され、どの方向が選ばれ、同じ結果がどう解釈されるかに影響する

P は単一主体の内部状態だけを意味しない。観測スケールによって、

- 個人：信念、将来期待、信用、自己評価
- 組織：契約期待、評判、慣行、文化
- 社会：制度期待、市場評価、社会規範、ナラティブ

などが P の構成候補となる。

P は直接観測される原始量ではなく、複数観測から推定される潜在場として扱う。

---

## 5. ΔP：観測後の更新

初期案では ΔP を単純な期待誤差、あるいは階層伝播の摩擦として置く案もあった。

現在は、ΔP をより一般に**結果観測後に生じる期待・信念・信用・意味の更新**として扱う。

概念順序は、

```text
A_t
 -> ΔK_t
 -> O_t = Observe(A_t, ΔK_t, C_t)
 -> ΔP_t = U(P_t, O_t)
```

と置く。

したがって、

```text
P_{t+1} = P_t + ΔP_t
```

となる。

必要な分野では減衰・慣性を追加できる。

```text
P_{t+1} = D(P_t) + U(P_t, O_t)
```

例えば自然減衰なら、

```text
D(P_t) = (1 - λ) P_t
```

のように置けるが、λ を普遍定数とはしない。

---

## 6. X：多元選好ベクトル

X は主体の行為方向を表す潜在ベクトルである。

```text
X_t = (x_1, x_2, ..., x_m)_t
```

各次元は必ずしも相互整合的でなくてよい。

したがって、価値場理論では以下を一般前提としない。

- 完備性
- 推移性
- 単一効用関数への還元
- 常時一貫した合理的選択

観測された A は、X が K / P / C によって射影されたものとして扱える。

```text
A_t ~ Π(X_t | K_t, P_t, C_t)
```

ここで Π は行為への射影・実装写像である。

極小時間では X と A の差が意味を持つが、有限時間では行為系列の方向が X の時間平均的射影として近づく場合がある。

---

## 7. V：価値場の派生表現

V は P/K/X/A と同列の原始変数ではなく、対象に応じて導出する**方向・圧力・勾配の表現**として扱う。

概念的には、

```text
V = G(K, P, X, C)
```

と置ける。

V を使う目的は、ある状態からどの方向へ行為・資源変化が起こりやすいかを、比較・可視化しやすい座標へ落とすことにある。

具体的な G は応用ごとに定義する。

---

## 8. 生成過程と推定過程

生成過程と推定過程は逆向きである。

### 生成側

```text
K_t, P_t, X_t, C_t
        ↓
       A_t
        ↓
      ΔK_t
        ↓
    Observation
        ↓
      ΔP_t
```

### 計測側

```text
A / ΔK / C / S / N
        ↓ inference
      X / P / V
```

この区別によって、自己申告をそのまま選好 X と同一視することや、観測された制約を即座に P と断定することを避ける。

---

## 9. 階層・スケール

個人・組織・社会・文明を、固定された独立世界としてではなく、観測スケールの違いとして扱う。

各スケールで、何を内生化し何を外生条件とするかが異なる。

| スケール | 主な内生対象 | 主な外生条件の例 |
| --- | --- | --- |
| 個人 | 判断・行為・局所資源更新 | 制度・市場・組織 |
| 組織 | 調整・再配分・契約・資源配分 | 市場・法・技術環境 |
| 社会 | 分布・制度・市場構造 | 技術・人口・地理 |
| 文明 | 長期技術・世界観・制度群 | 物理・地理条件 |

あるスケールの内生成果が、別スケールでは外生条件として現れる。

---

## 10. 階層間伝播

階層間の ΔK 伝播は、一般形として次のように表現できる。

```text
ΔK^(j)_t = M_{i->j}(P_t, C_t) · ΔK^(i)_t + ε_M
```

M は、

- 伝播率
- 減衰
- 歪み
- 時間遅延
- 情報損失
- 集約ルール

を含む写像である。

### 非対称性

一般に、

- **下位 -> 上位**：多数の局所変化の集約を必要とし、遅延・ノイズが大きい
- **上位 -> 下位**：制度・資源配分・技術条件等の制約として比較的強く現れる

という非対称性がある。

ただし、これは固定した社会階層の存在を前提とする法則ではなく、対象スケール間の接続構造についての仮説である。

---

## 11. 資本の扱い

「資本」は既存理論側で意味が複数あるため、価値場理論の原始変数にはしない。

主に次の2つへ射影する。

### 資源ストックとしての資本

現在利用可能な設備・金融資源・知識等を指す場合、K の一部として扱う。

### 蓄積構造としての資本

過去の行為と資源変換の結果形成された、再利用可能な構造・関係・設備・制度的履歴を指す場合、

```text
Capital_t = H(A_{<t}, ΔK_{<t})
```

のような履歴依存構造として扱う。

これにより、「資本＝資源」と「資本＝行動の痕跡」という異なる用法を、文脈ごとに区別できる。

---

## 12. 局所安定と均衡

価値場理論は静的均衡を前提としない。

ただし一定時間幅で、

```text
E[ΔK] ≈ 0
E[ΔP] ≈ 0
```

となる状態は、局所的安定状態として観察できる。

既存経済学の均衡概念は、この局所安定を特定軸へ射影したものとして扱える。

---

## 13. 現時点の未確定部分

以下は応用・実証で決めるべきであり、コアでは固定しない。

- K の標準次元
- P の標準次元
- X の具体的軸
- V の導出関数 G
- 行為射影 Π の具体形
- P 更新関数 U
- 階層間写像 M
- 減衰率・時間定数
- 組織・国家等を一つの主体として扱う近似条件

価値場理論のコアは、これらの係数を先に決めることではなく、**何が直接観測され、何が潜在で、どの差分がどの更新を生むかを明確にすること**にある。
