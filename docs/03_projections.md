# 価値場理論 — 既存概念・応用への射影

## 1. 射影の考え方

価値場理論では、既存理論の概念をそのまま原始変数として採用しない。

代わりに、

- K：資源
- ΔK：実現した資源変化
- P：期待・信念・信用・制度的背景等の場
- X：選好方向
- A：行為
- V：価値場の方向・圧力・勾配表現

へ射影する。

射影の目的は既存概念を否定することではなく、**何をどの観測軸・時間幅・主体スケールで切り取った概念なのかを明示すること**である。

---

## 2. 経済学への射影

### 2.1 消費と供給

価値場理論では、消費と供給を別の存在論として置かない。

どちらも資源変換 A を、主体・方向・会計視点を変えて見たラベルとして扱える。

```text
A : K_t -> K_{t+1}
```

ある主体の消費が、別主体にとって供給・売上・資源獲得となることがある。

したがって、コアでは「誰のどの K がどう変化したか」を先に記述し、消費・供給はその後に射影する。

### 2.2 効用

効用は、X または V の多元構造を、特定目的のためにスカラーへ射影したものとして扱う。

```text
U = u(X, V | context)
```

したがって、単一効用の存在を価値場理論の前提にはしない。

### 2.3 資本

資本は用法によって少なくとも2種類に分ける。

1. **現在利用可能な資源ストック**
   - 設備
   - 金融資源
   - 知識
   - 関係
   - インフラ

   これは K に射影する。

2. **過去の行為と資源変換が形成した再利用可能な構造**

```text
Capital_t = H(A_{<t}, ΔK_{<t})
```

   この意味では、資本は行動履歴から形成された構造である。

価値場理論では「資本」を独立の原始変数にせず、対象理論での意味を確認してから K または履歴構造へ射影する。

### 2.4 外部性

ある主体 i の行為が、別主体 j の資源状態を変える構造として表せる。

```text
A_i -> ΔK_j   (i != j)
```

正・負の評価は後段の射影であり、コア定義には含めない。

### 2.5 均衡

価値場理論は静的均衡を前提にしない。

一定の観測窓で、

```text
E[ΔK] ≈ 0
E[ΔP] ≈ 0
```

となる配置を局所安定状態として扱い、既存の均衡概念はその特定射影として理解する。

## 3. 市場・ネットワークへの射影

価値場を市場として記述する場合、単一アクターではなく複数ノード間の相互期待・反応・減衰を扱う。

### ノード

個人、企業、組織、制度単位など。

### エッジ

ノード間の価値変換・情報伝播・契約・信用関係。

### 反応係数

反応性をノード固有の能力だけに帰属させず、関係・接続側に置くことができる。

```text
ΔK_j = R_{ij}(P, C) · A_i + ε
```

ここで `R_ij` は、ある入力が別ノードの資源状態へどの程度・どの符号で伝わるかを表す。

### 減衰

摩擦、遅延、不確実性、制度、情報損失等は、接続写像の減衰・歪みとして扱う。

この表現により、サプライチェーン、バリューチェーン、信用ネットワーク等を同じ関係系へ射影できる。

---

## 4. 通貨・信用への射影

### 4.1 通貨

応用上、通貨を**価値判断を同期するためのプロトコル**として扱うことができる。

通貨は、

- 比較可能性
- 時間を越えた保存
- 他者との交換・同期

を支える座標系として機能する。

これは通貨の法的・歴史的定義ではなく、価値場理論から見た機能的射影である。

### 4.2 信用

信用には K と P の両側面がある。

- 利用可能な信用枠が実際の行為可能性を増やす場合：K
- その信用を支える期待・評価・返済見込み：P

そのため、信用を K または P のどちらか一方へ固定しない。

### 4.3 信用崩壊

応用モデルとして、信用崩壊を次のように表現できる。

- P 上では複数の将来期待が同時成立可能に見える
- 実現局面で、それらが同時に K / ΔK を要求する
- 基底資源制約が顕在化し、期待配置が維持できなくなる

つまり、資源そのものが突然消えるというより、**期待配置と資源制約の両立不能が露呈する現象**として記述できる。

---

## 5. 国家への射影

国家を価値場理論の原始主体とはしない。

応用上は、国家を通貨・制度・信用・資源配分を通じて形成される大域的ネットワークとして射影できる。

### 通貨圏

同一通貨・決済・債務体系に実効的に接続する主体群を、価値同期圏として扱う。

この視点では、国家機能の一部を次のように記述できる。

- 税・規制：可到達性・勾配の調整
- 福祉・移転：K の再配分・下支え
- 金融政策：期待 P と資源アクセス条件の調整
- 国境・法：接続条件 C の設定

ただし「国家 = 通貨圏」をコア定義とはせず、国家論への一つの射影として扱う。

### 準分散ネットワークとしての国家

現代国家を、完全中央集権でも完全分散でもないネットワークとしてみる応用も可能である。

- 人口・企業：ノード
- 税・福祉・金融・法：プロトコル
- 移住・資本移動：ネットワーク間移動
- 信認崩壊：接続維持条件の崩壊

この表現は政治制度の規範評価ではなく、接続構造の記述である。

## 6. 政治への射影

過去の議論では、政治を ΔK と期待更新へ射影するモデルが検討された。

例えば、

- 公約・宣言：将来 ΔK に関する P の形成
- 実現：観測された ΔK
- 支持率・評価：実績観測後の ΔP の一部を反映する指標

と置ける。

初期案では `ΔP = ΔK - E[ΔK]` のように期待誤差へ固定する案もあったが、現在は ΔP をより一般的な期待・信用・意味の更新として扱う。

したがって、支持率や選挙結果を ΔP そのものと同一視せず、ΔP を推定する観測の一つとして扱う。

---

## 7. 階層・組織への射影

過去には、

- L1：個人 = 労働市場
- L2：企業 = 取引・金融市場
- L3：制度 = 拘束条件

という固定階層モデルも検討された。

現在はこれを一般形とはせず、**分析対象に応じた有効力学系の切り方**と理解する。

組織では、

- 個人行動の調整
- 資源再配分
- 契約
- 評価
- 権限

を内生化し、それ以外を外生条件とする。

社会では、その組織・個人の分布や制度をさらに内生化する。

重要なのは「上位主体が本当に一つの意思で行動する」と仮定することではなく、どの集約規則を採用したかを明示することである。

---

## 8. 倫理・大義・功利主義への時間軸射影

価値場理論は規範理論ではないが、規範や社会原理が資源・探索へ与える動学的効果を射影できる。

過去の議論では、次の時間軸差が検討された。

- 倫理：過去・現在の被害や摩擦を抑える短期裁定
- 大義：未来の可能性・探索・未完成を正当化する長期配向
- 功利主義：基盤の効率・摩擦最小化を行う現在〜中期最適化

ここで重要なのは概念の価値判断ではなく、異なる時間軸の最適化を同一レイヤーで最大化しようとすると、トレードオフが発生することである。

静学的には改善に見える制約でも、探索空間を縮小することで将来の可到達 K や ΔK を失わせる可能性がある。

この効果は計測理論上、現在の ΔK だけでなく、将来の可到達集合や反実仮想との差として測る必要がある。

---

## 9. 古典・既存経済学との位置づけ

価値場理論は既存経済学を否定しない。

むしろ、既存理論で別々に扱われる概念を、共通の構造へ射影することを狙う。

例：

| 既存概念 | 価値場理論での主な射影 |
| --- | --- |
| 資源・予算制約 | K / C |
| 選好 | X |
| 行動・取引 | A |
| 実現成果 | ΔK |
| 期待・信用 | P |
| 効用 | X / V のスカラー射影 |
| 外部性 | `A_i -> ΔK_j` |
| 均衡 | 局所安定配置 |
| 資本 | K または A/ΔK の履歴構造 |
| 市場 | 多主体の A / P / ΔK 接続系 |

価値場理論の役割は、これらを一つに混ぜることではなく、**どのレイヤーの何を見ている概念なのかを揃えること**にある。

---

## 10. VVRC との関係

過去の議論で VVRC と価値場理論は別理論として接続するのではなく、同一構造の異なる記述粒度として整理された。

- 価値場理論：ミクロ〜マクロを含む一般形
- VVRC：その時間平均・低次元・マクロ射影として扱える

したがって、VVRC は将来統合すべき外部理論ではなく、価値場理論の一つの射影・表現として位置づける。

---

## 11. 射影時の原則

既存概念を価値場理論へ写す際は、次を明示する。

1. 観測主体
2. 観測スケール
3. 時間幅
4. K の対象成分
5. A の単位
6. ΔK の意味
7. P と C の境界
8. X / V を使う場合の推定方法
9. 集約規則
10. 規範評価を含むか否か

この条件が違えば、同じ語でも異なる射影になる。
