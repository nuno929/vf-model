## 1. 概要

価値場理論（Value-Field Theory; VFT）は、個人・組織・社会で生じる変化を、**実質側の資源状態と、名目・期待側の期待構造が、行動や資源流動をどの方向へ引きつけるか**として記述するための統合フレームである。

中心に置くのは、

- **K**：実質側の資源・資本・自由度を表す stock
- **P**：名目・期待側の多次元な期待 stock
- **A**：資源状態を変換する行為
- **ΔK**：区間内に実現した実質側の変化
- **E[ΔK]**：特定区間について形成される期待 flow

である。

**価値場とは、K と P の配置・関係によって生じる、行動または資源・流動性の移動方向への引力を指す。** K と P 自体を価値場と同一視せず、また独立した価値場変数 `V` も置かない。

個々人・主体ごとの選好、好き嫌い、合理性の差も独立した選好変数として置かず、**P の構造差・量的差、およびそこから形成される期待 ΔK の差**として扱う。

---

## 2. コア変数

| 記号 | 名称 | 役割 |
| --- | --- | --- |
| **K** | Real Resource / Capital Stock | 実質側の資源・資本・自由度を表す多元的な状態量 |
| **P** | Expectation Stock | 将来の行動・結果に対して個人または社会的に形成される多次元の期待構造 |
| **A** | Action | 資源状態を別の資源状態へ変換する行為 |
| **ΔK** | Realized Resource Change | 区間内に実現した実質側の資源状態の変化 |

### K：実質側の stock

K は金銭だけを意味しない。時間、身体、技能、知識、情報、関係、設備、インフラなど、**その時点で利用可能な資源・資本と、それによって成立する自由度**を多元的に扱う。

K の具体的な構成は観測スケール・対象領域ごとに定義する。

### P：名目・期待側の stock

P は、**将来の行動・結果に対して個人または社会的に形成される、多次元の期待構造**である。

信用、評価、契約、制度、慣行、公約、PR、ナラティブ等は、それぞれ形態は異なるが、将来に対する期待を形成・固定・伝播する P の構成要素として扱う。

P は対象・主体・観測レイヤーによって構造も量も異なりうる。同じ対象に対して異なる好き嫌い・評価・行為が生じる場合も、関連する P の構造差と、そこから形成される期待 ΔK の差として記述する。

### A と ΔK

A は資源状態を変換する作用として扱う。

```text
A : K_t -> K_{t+1}
ΔK_t = K_{t+1} - K_t
```

A によって実現した結果が ΔK として現れる。

## 3. 価値場と基本動学

### 価値場

価値場は、**名目・期待側の P と実質側の K の配置を同時に考慮したときに生じる、行動・資源・流動性の流れへの方向的な引力**である。

同じ P でも K が異なれば実現可能性・流動方向は変わり、同じ K でも P が異なれば主体が期待する変化と選択する A は変わる。

したがって、価値場は K または P の片方だけでは定まらず、両者の関係として現れる。

### stock / flow

| 側 | Stock | Flow |
| --- | --- | --- |
| 実質 | `K`：資源・資本・自由度の状態 | `ΔK`：区間内に実現した実質変化 |
| 名目・期待 | `P`：蓄積・共有された期待構造 | `E[ΔK]`：特定区間について期待される実質変化 |

P と `E[ΔK]` を分離する理由は、P が時間をまたいで保持される期待 stock である一方、`E[ΔK]` は特定区間について形成される期待 flow だからである。

`ΔP` を用いる場合、それは P という stock の差分であり、期待 flow そのものではない。

### ΔK の期待値

```text
E_t[ΔK_t] = f(P_t, ΔK_{t-1})
```

P は `E[ΔK]` と同一ではない。現在の期待 stock P と前区間の実現値 ΔK から、次区間の実質変化に対する期待 flow を形成する。

期待する ΔK は対象や時間軸ごとに異なりうるため、同一主体でも短期・長期で異なる行動方向を持ちうる。

### 行動・流動

最小限の関係は、概念的には次のように整理する。

```text
K_t + P_t
   ↓  value-field attraction
E_t[ΔK] / action & resource-flow direction
   ↓
A_t
   ↓
ΔK_t
```

A の具体的な選択則や、資源・流動性がどの程度動くかを表す関数は、対象領域の既存理論・応用モデルへ委ねる。

### P の動学

価値場理論は、P に固有の普遍的な更新式をコアとして定義しない。契約・制度変更・金融・宣言・情報伝播等によって直接形成・介入されうるためである。

経済学へ射影する場合、P を名目・期待側、K / ΔK を実質・実現側として対応させ、その具体関係は対象とする経済学理論の名目／実質・期待／実現の関係式を参照する。

## 4. 計測

価値場理論上の **K / P / A / ΔK は理論変数**であり、現実に得られる観測値をそのまま理論変数と同一視しない。

価格、取引、資産残高、契約、制度、統計、調査回答、行動ログ等、現実に観測されるものはすべて理論変数を構成・推定するための **proxy** として扱う。

```text
Observed data O
      ↓ operationalization / aggregation / estimation
K / P / A / ΔK
      ↓
Value-field analysis
```

したがって、「直接観測できる変数」と「潜在変数」を固定的に二分するのではなく、**各理論変数をどの proxy から、どの観測スケール・時間窓・集約規則で操作化するか**を明示する。

詳細は [docs/02_measurement.md](docs/02_measurement.md) を参照。

---

## 5. スケール

個人・組織・社会・文明といった区分は、固定された独立実体ではなく、**観測スケールと内生／外生境界の違い**として扱う。

あるスケールでの内生成果が、別スケールでは外生条件として現れうる。具体的な階層間伝播モデルはコアでは固定しない。

---

## 6. 理論の境界

価値場理論は現段階では、以下を直接目的としない。

- 独立した普遍的選好ベクトルを置くこと
- 独立した「価値場変数」を置くこと
- 単一の普遍的効用関数の提示
- P に固有の普遍的な更新式を定義すること
- A の普遍的な選択則を定義すること
- 射影先の経済理論が持つ名目／実質関係を独自式で置き換えること
- 特定の proxy や統計手法を普遍的な計測法として固定すること
- 特定の階層伝播式や応用モデルをコア定義として固定すること

本理論の役割は、**名目・期待側の P と実質側の K の関係から生じる行動・流動の引力を共通構造として記述し、それを観測 proxy から操作化できる形にすること**にある。
