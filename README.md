## 1. 概要

価値場理論（Value-Field Theory; VFT）は、個人・組織・社会で生じる変化を、**資源・期待／背景場・選好・行為・差分**の関係として記述するための統合フレームである。

中心に置くのは、実現した変化である **ΔK** と、それを生む **A（行為）**、行為の可到達性を規定する **K（資源）**、行為の方向づけや解釈に関わる **P（場）** である。X（選好）は行為方向を表す潜在ベクトルとして扱い、必要に応じて観測から逆推定する。

本理論は特定の経済・心理・政治モデルを置き換えることを目的としない。既存概念を同じ座標系に射影し、**何が資源で、何が行為で、何が実現差分で、何が期待・配向として推定されるか**を揃えることを目的とする。

## 2. コア変数

| 記号 | 名称 | 役割 |
| --- | --- | --- |
| **K** | Resource / Capability | 主体がアクセス可能な多元的資源。行為の可到達域を規定する状態量 |
| **ΔK** | Realized Resource Change | 行為によって実際に生じた資源状態の変化。主要な観測対象 |
| **P** | Field of Expectation / Belief / Constraint | 期待・信用・解釈・制度的背景など、行為の方向づけや伝播を変える場 |
| **X** | Preference Vector | 主体がどの方向へ動こうとするかを表す潜在的・多元的な選好 |
| **A** | Action | 資源状態を別の資源状態へ変換する観測可能な行為 |
| **V** | Value-field Representation | P/K/X/A/ΔKから導出する方向・圧力・勾配の表現。原始変数ではなく派生表現 |

### K：資源

K は金銭だけを意味しない。時間、身体、技能、知識、情報、関係、設備、インフラ、制度上利用可能な手段など、**行為に利用可能な資源**を多元ベクトルとして扱う。

「自由度」は K と別の実体ではなく、K と条件から定まる**可到達性**として理解する。

### X：選好

X は単一効用のスカラーではなく、多元的な方向ベクトルである。次元間の非整合を許し、完備性・推移性などの合理性公理を理論の前提にしない。

合理的に見える選択は、特定文脈・時間幅・射影上で局所的に現れるものとして扱う。

### A：行為

A は資源を別の資源状態へ変換する作用として扱う。

```text
A : K_t -> K_{t+1}
ΔK_t = K_{t+1} - K_t
```

実際の生成点としては個人の行為を最小単位とし、組織・社会の「行為」は個人行動の集約・調整・再配分として記述できる。

### P：場

P は K に還元できない。K が「何ができるか」を制約するのに対し、P は「どちらへ向かいやすいか」「何を期待するか」「同じ ΔK をどう解釈するか」に関わる。

P の具体的構成は観測スケールに依存する。個人では信念・期待・信用、組織では慣行・契約・評価、社会では制度・文化・市場期待などが候補となる。

## 3. 基本動学

価値場理論では、生成過程と観測・推定過程を分ける。

### 生成過程

概念上の最小順序は次のように置く。

```text
A -> ΔK -> Observation -> ΔP
```

1. 行為 A が実行される
2. 資源状態が変化し ΔK が生じる
3. その結果が観測・解釈される
4. 期待・信用・背景理解が更新され ΔP が生じる

P は次の行為の方向づけや、階層間で ΔK がどのように伝播するかに影響する。

### X と A の時間関係

極小時間では意図・選好 X と行為 A は分離できる。一方、有限時間では観測された行為系列は選好方向の射影・時間平均として近づく。

したがって X は独立した実体として常時直接観測するのではなく、A その他の観測から推定する潜在変数として扱う。

## 4. 階層・スケール

個人・組織・社会・文明といった階層は、完全に分離した実体ではなく、**観測スケールと内生／外生境界の違い**として扱う。

- 個人：局所的資源・行為・期待を内生化する
- 組織：個人行動の調整・再配分・契約関係を内生化する
- 社会：組織・個人の分布、制度、市場構造を内生化する
- より上位の地理・文明・技術条件は、対象とするスケールによって外生条件として扱う

ある階層での内生的結果は、別階層では外生条件として現れうる。

階層間伝播の参考表現として、次の写像を置ける。

```text
ΔK^(i+1) = M_i(P_i, C_i) · ΔK^(i)
```

ここで M_i は減衰・歪み・情報損失を含む接続写像、C_i は制度・物理条件などの観測可能な条件である。この式は固定的な唯一の法則ではなく、階層間伝播を記述するための一般形である。

一般に、下位から上位への波及は集約的・遅延的・ノイズが大きく、上位から下位への波及は制約として強く現れやすい。この非対称性を階層間写像の違いとして扱う。

## 5. 計測理論

射影表だけでは、概念を「どこに置くか」は決まっても、「何から観測・推定するか」が決まらない。そのため、価値場理論では生成モデルと別に計測理論を置く。

直接観測の中心は次のとおり。

- **A**：行為・選択・発話・取引
- **ΔK**：行為前後の資源差分
- **C**：制度・環境・契約などの条件
- **S**：自己申告
- **N**：必要な場合の生理・神経等の補助指標

これらから、**X・P・V** を逆推定する。

詳細は [docs/02_measurement.md](docs/02_measurement.md) を参照。

## 6. 既存理論への射影

価値場理論では、消費・供給・効用・資本・外部性・均衡などを原始概念として固定しない。同じ資源変換・期待・観測を、特定の軸へ射影した概念として扱う。

例：

- **消費 / 供給**：同一の資源変換を異なる主体・方向から見たラベル
- **効用**：多元的 X / V を特定目的にスカラー射影した表現
- **外部性**：ある主体の A が他主体の ΔK を生む構造
- **均衡**：一定時間幅で更新速度が小さい局所的安定状態
- **資本**：利用可能な資源ストックとして K に射影される場合と、反復された A / ΔK の履歴構造として扱う場合を区別する

通貨・国家・信用・政治なども同じコアから射影可能だが、これらはコア定義ではなく応用モデルとして扱う。

詳細は [docs/03_projections.md](docs/03_projections.md) を参照。

## 7. 理論の境界

価値場理論は現段階では、以下を直接目的としない。

- 単一の普遍的効用関数の提示
- すべての現象を一つの閉形式で予測すること
- 規範的に「何が正しいか」を決めること
- P・X を自己申告だけで直接観測できるとみなすこと

本理論の役割は、**説明が成立する前提構造と、観測・推定・射影の境界を揃えること**にある。
