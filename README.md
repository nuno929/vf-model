## 1. 概要

価値場理論（Value-Field Theory; VFT）は、個人・組織・社会で生じる変化を、**共通の実資源状態 K と、各主体が保持する期待形成状態 P の関係が、各主体の行動・意思決定 A をどのように条件づけるか**として記述する構造的フレームワークである。

VFT は現段階では、K / P から A を一意に予測する普遍的な選択則を与える理論ではない。複数主体・多次元の資源、期待、行動、変化を共通記法で扱うことを目的とする。

### K の存在論

K が参照する資源世界は主体ごとに別々に存在するのではなく、**同一の物理的・社会的な実資源世界**を前提とする。

各 `K_i,t` は、その共通の K のうち、主体 `i` が時点 `t` に実際にアクセス・利用・行使・参照可能な範囲を表す actor-relative な切り出しである。したがって、同じ設備・情報・インフラ等が複数主体の `K_i` に関係しうるが、資源そのものが主体ごとに複製されていることを意味しない。

### P と期待値

各 `P_i,t` は、主体 `i` が保持する将来の見通し・評価・選好・信用・信念等からなる多次元の期待形成状態である。

P を「期待 stock」と呼ぶのは、P 自体を特定時点の期待値とみなすためではなく、**将来価値への期待や行動を生成する側の蓄積構造であることに着目した呼称**である。

特定対象・区間について主体 `i` が望み・見込む実資源変化は、`E_i[ΔK]` として区別する。ここで相対的なのは期待評価であり、期待値関数に入る K は、主体 `i` が実際に利用可能な範囲 `K_i` でよい。

```text
E_i,t[ΔK] = f_i(K_i,t, P_i,t, ...)
```

`E_i[ΔK]` は期待側の変化量であり、価格、供給能力、時間、制度、他主体の行動等の制約によって、同じ大きさの実現変化 `ΔK` になるとは限らない。

## 2. コア変数

概念的には、

```text
K_t
K_i,t ⊆ / projection of K_t
P_t = {P_i,t}
A_t = {A_i,t}
```

と表す。

- **K**：共通の実資源世界を構成する多次元の資源・資本状態
- **K_i**：K のうち主体 `i` がアクセス・利用可能な範囲・状態
- **P_i**：主体 `i` の将来見通し・評価・選好・信用・信念等を保持する多次元期待形成 stock
- **A_i**：主体 `i` の行動・意思決定。必要に応じて観測・情報受容等、P を更新する主体的処理も含む
- **ΔK**：観測区間内に実現した K の状態変化
- **ΔP_i**：観測区間内に主体 `i` の P に実現した状態変化
- **E_i[ΔK]**：主体 `i` が特定対象・区間について望み・見込む期待実資源変化

K / P / A は単一スカラーを前提としない。分布化・平均化・集約は、必要に応じて観測・分析時に行う操作であり、コアの存在論ではない。

### 状態変化の記法

`ΔK` / `ΔP_i` は、観測区間の始点と終点で比較可能な表現を採る場合の状態変化を表す。加法的な表現が適用できる場合には、

```text
K_t+1 = K_t + ΔK_t
P_i,t+1 = P_i,t + ΔP_i,t
```

と書ける。

ただし Core が、健康・権利・情報・信念等を含むすべての K / P 成分に同一のベクトル空間や加法構造を要求するわけではない。必要なのは、各応用で同一対象の区間変化を比較可能にすることである。

`E[ΔK]` は rate としての flow ではなく、**特定対象・区間に対する期待区間変化**として扱う。

---

## 3. K / P の境界

K / P は対象物の種類だけで分類しない。

- **K**：実際に存在し、主体が利用・行使・参照できる資源・能力・権利・情報等
- **P**：それらを含む環境について主体が保持する見通し・評価・信用・信念等

例えば、契約上行使可能な権利は K、契約が履行される見込みは P となる。参照可能な情報は K、その情報から形成される将来見通しは P となる。

同じ現象が K / P の双方へ影響することはありうるが、同一 observable を根拠なく二重計上しない。

---

## 4. A と価値場

A は単一の「社会全体の行為」を意味しない。

```text
A_t = {A_i,t}_{i in I}
```

各 `A_i,t` は、主体 `i` が観測区間内に行った一つ以上の行動・意思決定を含みうる。区間内の順序が重要な場合はイベント順序を保持し、粗い時間粒度では順序を捨象した coarse-grained representation として扱う。

価値場は、**共通の K、その主体が利用可能な K_i、および各主体の P の配置・関係が、各 A を条件づけ、特定の行動を生じやすく／生じにくくする構造**を指す。

ここでいう「方向性」「引力」は action space 上の幾何学的ベクトルを意味しない。独立した価値場変数、引力量、普遍的な選択関数は置かない。

他主体や環境について主体 `i` がどう認識・予測しているかは、必要な範囲で `P_i` に含める。別の普遍的な観測写像を Core には追加しない。

---

## 5. K / P の変化

A は K / P を変化させる主要な主体的経路である。

```text
{A_i,t} -> ΔK_t
{A_i,t} -> {ΔP_i,t}
```

政策変更、価格提示、契約条件変更、情報伝達、観測・情報受容等による P の変化も、原則として何らかの主体的 A を介するものとして記述できる。

一方、記憶減衰等の微小・非主体的な P 変化の存在自体を否定する必要はない。ただし、それが観測可能な A や P proxy に意味のある差を生じない限り、Core では独立した変化経路として明示的にモデル化しない。

K には、減価償却・老朽化・自然消耗・災害等、A を介さない非主体的変化もありうる。これも独立した普遍変数を追加せず、必要な応用で考慮する。

## 6. 経済学への射影

経済均衡は VFT 固有の普遍則として定義しない。以下は既存経済学への**射影候補**である。

### ミクロ

各主体の `E_i,t[ΔK]` と、それに基づく A が相互作用する過程を、対象とする既存ミクロ経済学の均衡・調整過程へ対応させることができる。

VFT では需要側と供給側を別の存在論として分離しない。経済射影では、主体が望み・見込む資源変化 `E_i[ΔK]` を期待側、実際に生じた資源変化 `ΔK` を実現側として区別し、その差や調整を需要・供給・均衡過程へ対応させることができる。

交換・合意によって異種資源間の比較可能性が成立し、対象となる主体別の期待変化を同一の集約範囲で比較できる場合、**各主体の `E_i[ΔK]` の集約を期待総余剰（expected total surplus）への射影として扱うことができる。** 単純和を用いる場合は `Σ_i E_i[ΔK]` と表せるが、比較可能性、対象範囲、会計・換算規則、共有資源・重複アクセスの扱いを射影先で明示する。

期待総余剰は、実現した共通 K の純増 `ΔK` と同一ではない。期待した資源変化の一部は、各種制約によって実現しないことがある。

### マクロ

政策金利の変更、通貨供給量の操作、制度変更等は、まず政策主体の A として扱う。その A が各主体の見通し・信用条件等へ作用し、`ΔP_i` を誘発する。

前区間までに実現した資源変化と、当期の A が誘発する期待形成側の変化との相互作用を既存マクロ経済学へ対応させることは、一つの射影候補である。ミクロ／マクロ一般の時間構造を VFT が独自に定義するものではない。

Core の K / P を経済学上の real / nominal と同一視しない。K は resource / capability side、P は expectation / valuation side として置き、real / nominal の語は経済学への具体的射影でのみ用いる。

---

## 7. 計測

A のうち外部に実現した action event は直接観測できる場合がある。一方、内部の意思決定や観測・解釈過程は直接観測できず、proxy を要する場合がある。

個々の `P_i` の全構造も直接観測できるとは仮定しない。個人レベルでは選択・発話・調査等、集約レベルでは価格・金利・信用条件等を、必要な範囲で proxy として扱う。

`ΔK` / `ΔP` は A の結果 proxy として利用できる場合があるが、複数の A が相殺・重複しうるため、A を一意に同定する量ではない。

---

## 8. スケールと理論境界

個人・組織・社会・文明といった区分は、固定された独立実体ではなく、観測スケールと内生／外生境界の違いとして扱う。

価値場理論は現段階では、以下を普遍的に固定しない。

- K / P / A の単一スカラー化
- 多主体 A の確率分布化
- 組織・市場・社会の単一主体化
- 主体間関係の独立した普遍的関係変数
- 独立した選好変数 X
- 独立した価値場変数 V
- 単一の普遍的効用関数
- P の普遍的更新式
- `E[ΔK]` の普遍的形成式
- `E[ΔK]` を A 生成の必須中間変数とすること
- A の普遍的選択則
- ミクロ／マクロ均衡を VFT 固有の普遍則として定義すること
- 特定の観測方法・proxy・統計手法
