## 1. 概要

価値場理論（Value-Field Theory; VFT）は、個人・組織・社会で生じる変化を、**資源・期待構造・行為・差分**の関係として記述するための統合フレームである。

中心に置くのは、実現した変化である **ΔK** と、それを生む **A（行為）**、行為の可到達性を規定する **K（資源）**、将来の行動・結果に対して形成される **P（期待構造）** である。

個々人・主体ごとの選好、好き嫌い、合理性の差を独立した選好変数として置かず、**多次元の期待 stock である P の構造差・量的差、およびそこから形成される期待 ΔK の差**として扱う。

本理論の役割は、既存概念を同じ座標系に射影し、**何が資源で、何が行為で、何が実現差分で、何が期待構造として形成されるか**を揃えることにある。

---

## 2. コア変数

| 記号 | 名称 | 役割 |
| --- | --- | --- |
| **K** | Resource / Capability | 主体がアクセス可能な多元的資源。行為の可到達域を規定する状態量 |
| **ΔK** | Realized Resource Change | 行為によって実際に生じた資源状態の変化 |
| **P** | Expectation Field | 将来の行動・結果に対して個人または社会的に形成される多次元の期待構造 |
| **A** | Action | 資源状態を別の資源状態へ変換する観測可能な行為 |

### K：資源

K は金銭だけを意味しない。時間、身体、技能、知識、情報、関係、設備、インフラ、制度上利用可能な手段など、**行為に利用可能な資源**を多元ベクトルとして扱う。

「自由度」は K と別の実体ではなく、K と条件から定まる**可到達性**として理解する。

### P：期待構造

P は、**将来の行動・結果に対して個人または社会的に形成される、多次元の期待構造**である。

信用、評価、契約、制度、慣行、公約、PR、ナラティブ等は、それぞれ拘束力・共有範囲・持続性は異なるが、将来に対する期待を形成・固定・伝播する P の形態として扱う。

P は対象・主体・観測レイヤーによって構造も量も異なりうる。同じ対象に対して異なる好き嫌い・評価・行為が生じる場合も、独立した選好ベクトルを置かず、関連する P の構造差と、そこから形成される期待 ΔK の差として記述する。

P は実現した ΔK そのものではなく、実体変化と独立に介入・形成されうる。制度についても、その制度が将来どのように作用するかという期待構造は P に含まれ、実際に生じた資源状態の変化は K / ΔK 側に現れる。

P は直接観測される量とはせず、観測スケールに応じて複数の観測から逆推定する潜在場として扱う。

### A：行為

A は資源状態を変換する作用として扱う。

```text
A : K_t -> K_{t+1}
ΔK_t = K_{t+1} - K_t
```

個人の行為を最小の生成単位とし、組織・社会の「行為」を扱う場合は、集約規則を明示する。

## 3. 基本動学

### 生成過程

```text
K_t, P_t, C_t
      ↓
     A_t
      ↓
    ΔK_t
```

価値場理論のコアでは、A によって実現した資源変化 ΔK を生成側の主要差分として扱う。

### 期待の stock / flow

価値場理論では、期待を stock と flow に分ける。

| 側 | Stock | Flow |
| --- | --- | --- |
| 実体 | `K`：蓄積された資源状態 | `ΔK`：区間内に実現した資源変化 |
| 期待 | `P`：蓄積・共有された期待構造 | `E[ΔK]`：次区間に期待される実体変化 |

P と `E[ΔK]` を分離する理由は、P が制度・信用・評判・契約等として時間をまたいで保持される期待 stock である一方、`E[ΔK]` は特定区間に対して形成される期待 flow だからである。

`ΔP` を用いる場合、それは P の差分であり、期待 flow そのものを意味しない。

### ΔK の期待値

次区間の実体変化に対する期待値は、現在の P と前区間に実現した ΔK から形成される。

```text
E_t[ΔK_t] = f(P_t, ΔK_{t-1})
```

P は契約・宣言・信用・金融・PR 等によって実体変化と独立に介入可能であり、`E[ΔK]` と同一ではない。`ΔK_{t-1}` は前区間の実現値として、現在の P とともに次区間の実体期待を形成する。

期待する ΔK は対象や時間軸ごとに異なりうるため、同一主体でも短期・長期で異なる行為方向を持ちうる。価値場理論では、この差を独立した選好変数ではなく、P と期待 ΔK の構造として扱う。

### P の動学

価値場理論は、P に固有の普遍的な更新式をコアとして定義しない。P は実現した ΔK の観測によって変化しうる一方、契約・制度変更・金融・宣言・情報伝播等によって直接形成・介入されうるためである。

したがって、`P_{t+1} = U(P_t, ΔK_t, ...)` のような一般更新則を置くことは、未解決事項ではなく**意図的に理論の射影先へ委ねる境界**とする。

経済学へ射影する場合、P を名目・期待側、K / ΔK を実質・実現側として対応させ、その具体的な関係は、対象とする経済学理論が持つ名目／実質・期待／実現の関係式を参照する。価値場理論が独自の一般式でそれらを置き換えることはしない。

### 計測過程

```text
A / ΔK / C / S / N
        ↓ inference
          P
```

P は観測値そのものと同一視せず、観測から推定する。

---

## 4. スケール

個人・組織・社会・文明といった区分は、固定された独立実体ではなく、**観測スケールと内生／外生境界の違い**として扱う。

あるスケールでの内生成果が、別スケールでは外生条件として現れうる。具体的な階層間伝播モデルはコアでは固定しない。

---

## 5. 計測理論

射影表だけでは、概念を「どこに置くか」は決まっても、「何から観測・推定するか」が決まらない。そのため、価値場理論では生成モデルと別に計測理論を置く。

直接観測の中心は次のとおり。

- **A**：行為・選択・発話・取引
- **ΔK**：行為前後の資源差分
- **C**：制度・環境・契約などの条件
- **S**：自己申告
- **N**：必要な場合の生理・神経等の補助指標

これらから **P** を逆推定する。

詳細は [docs/02_measurement.md](docs/02_measurement.md) を参照。

---

## 6. 理論の境界

価値場理論は現段階では、以下を直接目的としない。

- 独立した普遍的選好ベクトルを置くこと
- 独立した「価値場表現」変数を置くこと
- 単一の普遍的効用関数の提示
- すべての現象を一つの閉形式で予測すること
- P に固有の普遍的な更新式を定義すること
- 射影先の経済理論が持つ名目／実質関係を独自式で置き換えること
- 規範的に「何が正しいか」を決めること
- P を自己申告だけで直接観測できるとみなすこと
- 特定の階層伝播式や応用モデルをコア定義として固定すること

本理論の役割は、**説明が成立する前提構造と、観測・推定の境界を揃えること**にある。
