## 1. 概要

価値場理論（Value-Field Theory; VFT）は、個人・組織・社会で生じる変化を、**実質側の資源状態 K と名目・期待側の期待構造 P の関係が、各アクターの行動・意思決定 A をどの方向へ生じさせるか**として記述するための統合フレームである。

K / P / A は単一量を前提としない。

- 各アクター `i` は、自身がアクセス可能な多次元の `K_i` を持つ
- 各アクター `i` は、自身が観測・参照可能な多次元の `P_i` を持つ
- `A_i` は、そのアクターが観測区間内に行う複数の行動・意思決定を含みうる
- マクロでは、複数アクターの K / P / A が同時に存在する

概念的には、

```text
K_t = {K_i,t}
P_t = {P_i,t}
A_t = {A_i,t}
```

と表せる。ただしこれは確率分布を意味しない。**分布化・平均化・集約は、必要に応じて観測・分析時に行う操作であり、コアの存在論ではない。**

中心に置くのは、

- **K**：各アクターがアクセス・利用可能な実質側の資源・資本・自由度を表す多次元 stock
- **P**：各アクターが観測・参照可能で、意思決定に作用しうる多次元な期待 stock
- **A**：K / P が形成する価値場の引力が、各アクターの行動・意思決定として実現したもの
- **ΔK**：区間内に実現した実質側の変化
- **ΔP**：区間内に実現した名目・期待 stock の変化
- **E[ΔK]**：特定区間について形成される期待 flow

である。

**E[ΔK] を P から独立して記述する理由は、P が期待 stock であるのに対し、E[ΔK] が特定区間に対する期待 flow だからである。E[ΔK] を価値場から A が生じるための必須中間変数とはしない。**

**価値場とは、各アクターから見た多主体・多次元の K と P の配置・関係によって、それぞれの A を生じさせる方向性である。価値場の引力は別の中間変数として置かず、実現したものを A として扱う。**

主体間の関係を別の普遍的な関係変数として置くことを前提としない。資源へのアクセス可能性は `K_i` に、期待・情報・制度等への観測・参照可能性は `P_i` に反映される。

## 2. コア変数

| 記号 | 名称 | 役割 |
| --- | --- | --- |
| **K** | Real Resource / Capital Stock | 各アクターがアクセス・利用可能な実質側の資源・資本・自由度を表す多次元状態 |
| **P** | Expectation Stock | 各アクターが観測・参照可能で、意思決定に作用しうる多次元の期待構造 |
| **A** | Action / Decision | 各アクターの行動・意思決定。区間内に複数存在しうる |
| **ΔK** | Realized Real Change | 区間内に実現した実質側の変化 |
| **ΔP** | Realized Nominal / Expectation-stock Change | 区間内に実現した P の変化 |
| **E[ΔK]** | Expected Real Change | 特定区間に対して形成される期待 flow |

### K：実質側の stock

各アクター `i` の K は単一量ではなく、多次元状態として扱う。

```text
K_i,t = (K_i,1, K_i,2, ..., K_i,n)_t
```

K は、**そのアクターがその時点でアクセス・利用可能な資源・資本と、それによって成立する自由度**を表す。

同じ社会・組織に属していても、資源へのアクセス、権限、利用可能な手段等が異なれば `K_i` は異なる。

時間、身体、技能、知識、情報、関係、設備、資金、インフラ等を含みうる。

マクロの K も一つのスカラーへ還元することを前提とせず、複数アクター・複数成分の状態を必要な目的に応じて集約する。

### P：名目・期待側の stock

各アクター `i` の P は、**そのアクターが観測・参照可能で、意思決定に作用しうる多次元の期待構造**である。

同じ社会・組織に属していても、観測している情報、契約、信用、評価、制度との接続等が異なれば `P_i` は異なる。

信用、評価、契約、制度、慣行、公約、PR、ナラティブ等は、将来に対する期待を形成・固定・伝播する P の構成要素として扱う。

P は履歴依存の stock であり、時点 `t` の P は、前区間までの各アクターの A と実現 ΔK を含む過去の履歴が蓄積された状態として扱う。

観測窓の開始時点で外部から与えられたように見える P も、原則として観測窓より前の A や実現 ΔK が既に織り込まれた状態である。

### A：各アクターの行動・意思決定

A は単一の「社会全体の行為」を意味しない。

```text
A_t = {A_i,t}_{i in I}
```

各 `A_i,t` は、アクター `i` が観測区間内に行った一つ以上の行動・意思決定を表す。

組織や市場を扱う際も、必要がない限り複数アクターの A を一つの主体行動へ還元しない。

A は K / P の双方を増減させうる。

```text
{A_i,t}
   ↓
ΔK_t / ΔP_t
```

## 3. 価値場と基本動学

### 価値場

価値場は、**各アクターから見た多主体・多次元の K / P の配置が、それぞれの A にどの方向性を与えるか**を表す。

```text
past {A_i}, realized ΔK
          ↓
         P_t
          ↓
{K_i,t}, {P_i,t}
        ↓  value field
      {A_i,t}
        ↓
     ΔP_t / ΔK_t
```

ここで `{A_i,t}` は確率分布ではなく、各アクターの行動・意思決定の集合である。

必要に応じて A を頻度分布・比率・平均・ネットワーク流等へ集約できるが、それは計測・分析上の射影であり、価値場理論が A 自体を「分布」と定義するものではない。

### stock / flow

| 側 | Stock | 実現変化 | 期待 flow |
| --- | --- | --- | --- |
| 実質 | `K`：各アクターがアクセス可能な多次元の資源・資本・自由度 | `ΔK`：実現した実質変化 | `E[ΔK]`：特定区間について期待される実質変化 |
| 名目・期待 | `P`：各アクターが観測・参照可能な期待構造 | `ΔP`：P stock の実現変化 | — |

`E[ΔK]` は P とは異なる時間概念を持つため独立して記述する。P は蓄積された期待 stock、`E[ΔK]` は特定区間についての期待 flow である。

`ΔP` は P stock の差分であり、期待 flow そのものではない。

### E[ΔK] と均衡への射影

`E[ΔK]` は主体・対象・時間軸ごとに形成される期待 flow であり、P の分析・射影に用いる。

```text
E_i,t[ΔK] = f_i(P_i,t, history, ...)
```

ただし、この関係は価値場から A を生成する普遍的な中間過程を意味しない。具体的な形成式は射影先・対象領域ごとに異なるため、コアでは固定しない。

経済学への射影では、各主体の `E_i,t[ΔK]` に基づく A が十分な数・量で相互作用する過程を、既存のミクロ経済学が扱う均衡過程へ対応させられる。

集約・マクロ側では時間構造が異なり、**前区間に実現した `ΔK_{t-1}` が当期の実質側の状態・制約へ反映され、それに対して当期の `ΔP_t` が名目・期待側から作用し、次の A と `ΔK_t` に影響する**と整理できる。

```text
ΔK_{t-1}
   ↓
  K_t  ←→  P_t
            ↑
           ΔP_t
             ↓
           {A_i,t}
             ↓
           ΔK_t
```

この相互調整は、経済領域では既存のマクロ経済学の調整過程へ射影できる。国家スケールでは、金利や通貨供給量の操作は ΔP 側への代表的な介入として扱える。

ミクロ／マクロの均衡過程そのものを、価値場理論独自の普遍則としては定義しない。

### K / P の変化

A は K / P の双方を変化させる主要経路である。

```text
{A_i,t} -> ΔK_t
{A_i,t} -> ΔP_t
```

P については、独立した「外生変化」をコアとして置かない。現在の P に外生的に見える変化は、原則として前区間までの A や実現 ΔK の履歴として時間方向に取り込む。

一方で、P は A によって直接変化させられるため、`ΔP` は個人・組織・市場・国家等の各観測スケールで介入経路となりうる。介入の具体形は対象領域ごとに異なる。

実現した ΔK は、その後の P の形成・維持・毀損に関わりうる。ただし、その具体的な更新関数はコアでは固定しない。

> **注記：** K は減価償却・老朽化・自然消耗・災害等、A を介さない非主体的変化によっても増減しうる。

## 4. 計測

A は原理的に不可観測ではない。個人・局所レベルでは、選択、取引、移動、発話、投資、労働等として比較的直接に観測できる。

ただし、各アクターが持つ複数の A を長期間・多数主体について網羅的に追跡するコストは高い。

そのため、組織・市場・マクロ等では、全 `{A_i}` を直接追う代わりに、**名目側の変化量 ΔP と実質側の変化量 ΔK を主要 proxy として用いる**。

ΔK を A の proxy として用いる場合は、必要に応じて前記の非主体的変化を考慮する。

ΔP / ΔK も単一量とは限らず、対象・スケールに応じた多次元変化または集約量として操作化する。

## 5. スケール

個人・組織・社会・文明といった区分は、固定された独立実体ではなく、観測スケールと内生／外生境界の違いとして扱う。

スケールを上げても K / P / A を自動的に一主体・一変数へ集約しない。必要な場合のみ集約規則を明示する。

同一の環境でも各アクターがアクセス可能な K と観測・参照可能な P は異なる。観測範囲外のアクターによる A は、観測上は外部に見えても、存在論上の非主体的変化とは区別する。

---

## 6. 理論の境界

価値場理論は現段階では、以下を直接目的としない。

- K / P / A を単一スカラーへ還元すること
- 多主体 A を確率分布として定義すること
- 組織・市場・社会を自動的に単一主体として扱うこと
- 主体間関係を独立した普遍的関係変数として置くこと
- 独立した普遍的選好ベクトルを置くこと
- 独立した「価値場変数」を置くこと
- 単一の普遍的効用関数の提示
- P に固有の普遍的な更新式を定義すること
- `E[ΔK]` を A 生成の普遍的な中間変数として固定すること
- ミクロの期待 ΔK 均衡や、前区間 ΔK と当期 ΔP のマクロ調整過程を独自の普遍則として定義すること
- A の普遍的な選択則を定義すること
- 射影先の経済理論が持つ名目／実質関係を独自式で置き換えること
- 特定の観測方法や proxy を普遍的な計測法として固定すること

本理論の役割は、**各アクターから見た多主体・多次元の K / P の関係から各 A が生じ、その結果が ΔP / ΔK として現れる構造を共通記法で扱い、P に対応する期待 flow を E[ΔK] として区別すること**にある。
